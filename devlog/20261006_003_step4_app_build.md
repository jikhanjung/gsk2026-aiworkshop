## 한 일

- `steps/step4_bookmark.html` — step3 에 덧붙이는 방식(추가 부분에 `[Step 4]` 주석).
  - ☆/★ 북마크: `Set` + `localStorage`(키 `gsk2026.bookmarks`, 읽기·쓰기 모두 try/catch).
  - 탭 2개(전체 프로그램 / 내 일정 (n)). 내 일정은 날짜별 시간순, 겹치는 발표는 빨간 테두리 + "⚠ 시간 겹침".
  - 카드 그리기를 `talkHTML()` 로 빼서 두 화면이 공유. ☆ 클릭은 `main` 에 이벤트 위임.
- `steps/app.html` — 완성본 (strati2026 Django 버전 디자인 참고, 바닐라 JS 한 파일).
  - 하단 탭: 프로그램 / 세션 / 검색 / 내 일정. hash 라우팅 `#/program`, `#/sessions`, `#/session/{code}`,
    `#/search`, `#/my`, `#/talk/{id}`, `#/abstract/{id}`. 화면별 스크롤 위치 기억(상세 → 뒤로 시 복원).
  - 발표 상세: 기조강연 배지, 세션 링크, 저자, 초록 본문, 키워드 칩(누르면 검색), 소속(접기).
  - 프로그램에 일정이 없는 초록(포스터 등 약 180건)도 세션 화면·검색에서 보이게 `#/abstract/{id}` 추가.
  - 검색: 제목·저자·키워드·세션 + 초록 본문. 소문자 색인을 미리 만들어 둠. 2글자 이상, 최대 100건 표시,
    본문에서만 맞으면 앞뒤 60자 스니펫 + 하이라이트.
  - 내 일정: 날짜별 + 겹침 개수, 북마크 내보내기(Blob → `bookmarks.json`) / 불러오기(FileReader, 병합, 없는 id 무시) / 모두 지우기.
  - 학회명·장소·날짜·장소 목록은 전부 `DATA.meta`/`DATA.talks` 에서 뽑음 (하드코딩 없음). 학회 기간이면 오늘 날짜로 시작.
- `build.py` — `python build.py <템플릿> <json> <출력>`. `__DATA__` 가 정확히 1번인지 확인, `</` → `<\/`.
- `scripts/prepare_data.py` — 시간을 `HH:MM` 두 자리로 맞추는 `hhmm()` 추가 후 데이터 재생성.

## 핵심 발견

- 원본 데이터에 `time_end` 가 `"8:50"` 처럼 한 자리 시각인 발표가 5건 있었음. 문자열 비교로 겹침을 계산하면
  `"8:50" > "08:30"` 이 되어 틀린다 → 데이터 단계에서 두 자리로 통일(README 의 스키마 규칙에도 명시).
- 하이라이트를 "이스케이프한 HTML 에 정규식 치환" 으로 하면 `amp` 같은 검색어가 `&amp;` 엔티티를 깨뜨린다.
  완성본은 원문을 검색어로 split 한 뒤 조각마다 이스케이프하는 방식으로 바꿈. (step3/4 는 수업용 단순 버전 유지)
