# 005. 실습 데이터를 GSK 2025 추계학술대회 프로그램북으로 교체

- 날짜: 2026-10-06
- 상태: 완료

## 한 일

- GSK 2026 추계학술대회 정보 조사: 2026-10-27~30 여수엑스포컨벤션센터. **2026 상세 프로그램북은 아직 미공개**
  (공개된 건 안내서 PDF 뿐) → 사용자 결정으로 **2025 프로그램북**을 데이터 원본으로 사용.
- 2025 프로그램북(124쪽, 16.5MB)을 학회 공지 게시판 첨부에서 받아 `data/src/gsk2025_program_book.pdf` 에 둠(git 미추적).
  첨부 다운로드는 `?pmode=…&smode=ajax&fn=fileDownload&seq=…&bseq=…&fnm=…` (GET).
- `scripts/parse_program_book.py` (pymupdf) 작성 → `data/conference.json` (같은 스키마, 0.33MB).
  - 날짜 머리(20pt), 세션 머리(x≈62, 11pt 이상, 두 줄 이어짐 처리), 발표장(x>400 "제N발표장"), 시간(x≈58),
    제목(9.4pt 이상) / 저자·꼬리표(그보다 작음, 제목 뒤/앞)로 구분. 오른쪽 색인 탭(x>500)·쪽번호(y>680) 제거.
  - 결과: 3일, 9개 발표장, 세션 38개(G01–G17, S01–S17, W01–02, F01, Y), 구두 382건(특별강연·기조연설 plenary 5),
    포스터 229건(P001–P209, Y001–Y020 번호 빠짐·중복 없음) → 포스터는 일정 없는 abstracts.
  - 버린 칸(제목 없음)을 모두 확인: 휴식·중식·개회식·폐회·총회·리셉션 등 63칸, 발표 누락 없음.
- `steps/app.html`: 초록 본문이 없으면 상세에 "초록 본문이 없습니다." 표시.
- `scripts/smoke_test.js`: 초록 본문 유무에 따라 검사(본문 검색은 본문 있을 때만), 일정 없는 초록을 저자로 찾는 검사 추가.
  STRATI 데이터·GSK 데이터 양쪽에서 `check.py` 통과.
- 문서: README "데이터", CLAUDE.md 데이터 섹션, HANDOFF, `docs/colab_guide.md`·노트북의 데이터 의존 문구(개수, "기조강연 등") 일반화.

## 핵심 발견

- 글꼴 이름은 한글/영문에 따라 달라서(영문 제목 AppleSDGothicNeo-Bold 10.9, 한글 제목 YDVYGO35 9.5,
  한글 저자는 "휴식" 같은 꼬리표와 같은 Hakgyoansim 7.7) **글꼴이 아니라 크기 + 제목 앞/뒤 위치**로 구분해야 한다.
- 원문 오타: 10/29 제3발표장 `12:00-15:15`(→ 12:15). 같은 발표장에서 다음 발표 시작보다 늦게 끝나면 자르도록 보정(로그 출력).
- 저자 칸에 "김복철 (前 NST이사장, 前 KIGAM원장)" 처럼 괄호 안 쉼표가 있음 → 괄호 깊이를 보며 나눔.
- 프로그램북엔 초록 본문이 없고, 초록집 PDF 는 회원 로그인이 필요(비로그인 다운로드 시 "다운로드권한이 없습니다").
- 발표자 표시(`*`)는 지금 스키마에 없어 버림(first_author = 첫 저자).
