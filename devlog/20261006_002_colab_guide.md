## 핵심 발견 (주의사항으로 정리한 것)

- **런타임 초기화 시 업로드 파일·생성 HTML 소실** → "이전 셀 모두 실행" 복구 + 바로바로 다운로드.
- **Chrome 은 `file://` 페이지들이 localStorage 를 공유**한다 → Step 4 북마크가 Step 5 파일에서도 보임(정상).
  Colab 미리보기의 저장소는 내려받은 파일과 별개.
- `%%writefile` 첫 줄과 `__DATA__` 자리를 학생이 지우는 실수가 가장 흔할 것 → 오류 메시지 표에 포함.
- 결과 HTML 에 데이터 전체(초록 본문)가 들어 있음 → 파일 공유 = 데이터 공유. 공개 업로드 금지 명시.
- 실습실 PC 보안 정책(다운로드·로컬 HTML 실행 차단) 가능성 → 강사 사전 점검 항목.
