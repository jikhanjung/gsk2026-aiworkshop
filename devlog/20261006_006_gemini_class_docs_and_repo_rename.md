# 006. Gemini 활용 수업 방식으로 문서 재구성, 저장소 이름 변경

- 날짜: 2026-10-06
- 상태: 완료 (실제 Gemini in Colab 으로는 미검증)

## 배경

수업이 **AI 활용 수업**으로 정해졌다. 학생에게 노트북을 처음부터 주지 않고, 빈 Colab 노트북에서
**Gemini 에게 프롬프트를 입력하며** 노트북을 구성해 학회 시간표 앱 HTML 을 만들게 한다.
지금까지 만든 템플릿·노트북은 **모범 답안**으로, 수업 마지막에 공개해 비교하게 한다.

## 한 일

- `docs/gemini_practice_guide.md` (학생용, 새로 작성)
  - **완성 기준 9개**(단일 HTML, 오프라인, 날짜·발표장·검색, 북마크·내 일정·유지·겹침)와 확인 방법.
  - 작업 루프(말하기 → 코드 확인·실행 → 다운로드해서 열기 → 기준과 비교), 단계 0~5 프롬프트 예시.
  - 단계 0 에서 **조건을 먼저 못 박기**: HTML 하나, 데이터 내장, fetch·서버·CDN 금지.
  - **Gemini 가 자주 하는 실수 표**: fetch 로 데이터 읽기(다운로드 후 빈 화면), CDN, Flask/Streamlit,
    f-string 과 JS `{}` 충돌, `</script>` 미이스케이프, 기능 재작성 시 회귀, innerHTML 이스케이프 누락,
    시각 문자열 비교, 필드 이름 지어내기.
  - Gemini 사용 주의(학교 계정 비활성 가능성, 사용량 한도, 데이터를 채팅에 붙여 넣지 말 것, 브라우저 콘솔 오류는 직접 복사해 전달).
  - 제출물(HTML·노트북·회고)과 모범 답안 비교 과제.
- `docs/instructor_guide.md` (강사용, 새로 작성): 수업 전 점검, 3시간 진행 예시, 막히는 지점별 개입 힌트,
  평가 기준(완성 50 / 과정 30 / 회고 20)과 채점 절차, 모범 답안 비교 토론 질문.
- `docs/colab_guide.md` → `docs/reference_notebook_guide.md` 로 이름 변경, 머리말에 "수업 마지막 공개용 모범 답안 안내서" 명시.
- README·CLAUDE.md·HANDOFF 를 새 수업 방식에 맞게 갱신. README 의 기존 노트북 진행표는 "(대안) 강의식 진행" 으로 남김.
- GitHub 저장소 이름 `gsk2026` → **`gsk2026-aiworkshop`** (`gh repo rename`, origin URL 갱신, 문서 내 Colab 링크 갱신).

## 핵심 발견

- Chrome 은 로컬 HTML 들이 localStorage 를 공유한다 → 채점할 때 **다른 학생 파일의 북마크가 보일 수 있음**
  (같은 키를 쓴 경우). 강사 안내서 채점 절차에 반영.
- 실습 데이터는 시각이 `HH:MM` 로 정규화돼 있어 학생이 문자열 비교로 겹침을 짜도 우연히 맞는다 → 토론 주제로 활용.
