# 모범 답안 노트북 안내서 — 학회 프로그램 웹앱 만들기

> **수업 마지막에 공개하는 문서입니다.** 수업 본 과정은 학생이 Colab 의 Gemini 와 대화하며 직접 노트북을
> 구성하는 방식이고([`gemini_practice_guide.md`](gemini_practice_guide.md)), 이 문서는 강사가 미리 만든
> 모범 답안 노트북 `gsk2026_practice.ipynb` 를 따라가며 **내가 만든 것과 비교**할 때 씁니다.
> 노트북 링크: https://colab.research.google.com/github/jikhanjung/gsk2026-aiworkshop/blob/main/gsk2026_practice.ipynb

학회 발표 데이터(JSON)를 받아 **Google Colab** 에서 웹앱 HTML 파일을 만들고, 내려받아
**내 PC 브라우저에서 직접 써 보는** 실습입니다. 마지막에는 아래 기능을 갖춘 HTML 파일 하나가 남습니다.

- 날짜·장소별 발표 프로그램 보기
- 제목·저자·초록 검색
- ☆ 북마크 → **내 일정**(시간순 타임테이블, 시간이 겹치는 발표 표시)
- 발표 상세(초록·저자·소속·키워드)

> 이 파일 하나에 데이터가 모두 들어 있어서, 인터넷이나 서버 없이 더블클릭만으로 열립니다.

## 2. 노트북 구성 한눈에 보기

| 단계 | 하는 일 | 배우는 것 |
|------|---------|-----------|
| 준비 | 도우미 함수 정의, 데이터 불러오기 | 파일 업로드, JSON 읽기 |
| Step 0 | 데이터 살펴보기 | JSON 구조, pandas 표 |
| Step 1 | 파이썬만으로 HTML 만들기 | 데이터가 HTML 이 되는 원리 (f-string) |
| Step 2 | JS 로 발표 목록 그리기 | 배열 → HTML, `innerHTML`, 이스케이프 |
| Step 3 | 날짜·장소 필터, 검색 | 상태(state) + `render()` 패턴, 이벤트 |
| Step 4 | ☆ 북마크와 내 일정 | `localStorage`, 시간 겹침 계산 |

| 과제 | 직접 기능 추가 | |

모든 단계는 같은 순서로 진행합니다.

```
템플릿 셀(%%writefile) 실행  →  build()  →  preview()  →  download()  →  내 PC 에서 열기
   HTML 틀을 파일로 저장        데이터 넣기    Colab 에서 미리보기   내려받기
```

## 3. 준비 셀

### 3-1. 도우미 함수 셀 실행

노트북 맨 위의 **준비** 셀을 실행합니다(셀 왼쪽 ▶ 또는 `Ctrl+Enter`).
아래 세 함수가 만들어집니다. 내용은 몰라도 되지만, 이름과 하는 일은 알아 두세요.

| 함수 | 하는 일 |
|------|---------|
| `build("템플릿.html", "결과.html")` | 템플릿의 `__DATA__` 자리에 데이터를 넣어 결과 HTML 을 만든다 |
| `preview("결과.html")` | Colab 화면 안에서 결과 HTML 을 띄워 본다 |
| `download("결과.html")` | 결과 HTML 을 내 PC 로 내려받는다 |

### 3-2. 데이터 불러오기

둘 중 강사가 안내한 방법을 씁니다.

**방법 A — 파일 업로드**
1. 데이터 셀을 실행하면 **파일 선택** 버튼이 나옵니다.
2. 미리 받아 둔 `conference.json` 을 고릅니다.
3. `sessions …, talks …, abstracts …` 처럼 개수가 출력되면 성공.

**방법 B — 구글 드라이브 연결**
1. 드라이브 셀을 실행하면 권한 창이 뜹니다 → 내 계정 선택 → **허용**.
2. 강사가 공유한 `conference.json` 을 **내 드라이브에 바로가기 추가**(또는 사본)해 둡니다.
3. 셀 안의 경로(`/content/drive/MyDrive/…`)를 내 파일 위치에 맞게 고치고 실행합니다.

> 💡 왼쪽 📁 **파일** 패널을 열면 런타임에 있는 파일들이 보입니다. `conference.json` 이 보이면 준비 끝.

## 4. Step 0 — 데이터 살펴보기

데이터는 네 부분으로 되어 있습니다.

| 키 | 내용 | 주요 필드 |
|----|------|-----------|
| `meta` | 학회 정보 | `name`(학회명), `place`, `days`(날짜 목록) |
| `sessions` | 세션 | `code`, `title` |
| `talks` | 발표 일정 | `id`, `date`, `day_label`, `time_start`, `time_end`, `room`, `session`, `title`, `first_author`, `kind`, `abstract_id` |
| `abstracts` | 초록 | `id`, `session`, `title`, `authors[]`, `affiliations[]`, `abstract`, `keywords[]` |

- 발표(`talks`)와 초록(`abstracts`)은 `talks[i].abstract_id` ↔ `abstracts[j].id` 로 연결됩니다.
  `abstract_id` 가 비어 있는(`None`) 발표도 있습니다(워크숍 등).
  포스터처럼 발표 일정이 없는 초록도 있고, 데이터에 따라 초록 본문(`abstract`)이 비어 있을 수 있습니다.
- 셀을 실행해 표(DataFrame)로 보고, 날짜별·장소별 발표 수를 세어 보세요.

하지만 이 방식은 필터·검색처럼 **화면에서 바로 반응하는 기능**을 만들기 어렵습니다 → Step 2부터 JS 로.

## 6. Step 2~5 — 템플릿 고치기 → 만들기 → 보기

### 6-1. 템플릿 셀

각 단계에는 이렇게 시작하는 셀이 있습니다.

```
%%writefile step2_list.html
<!doctype html>
<html lang="ko">
…
<script>
const DATA = __DATA__;
…
</script>
```

- **첫 줄 `%%writefile 파일이름` 은 지우거나 띄어 쓰지 마세요.** 이 줄이 "셀 내용을 파일로 저장하라"는 뜻입니다.
- 이 셀의 내용은 **파이썬이 아니라 HTML/CSS/JS** 입니다. 실행해도 화면에 `Writing step2_list.html` 만 나옵니다.
- `const DATA = __DATA__;` 의 **`__DATA__` 는 그대로 두세요.** `build()` 가 이 자리에 데이터를 넣습니다.
  (지우거나 두 번 쓰면 `build()` 가 오류를 냅니다.)

### 6-2. 만들고 보기

템플릿 셀 바로 아래 셀:

```python
build("step2_list.html", "out_step2.html")
preview("out_step2.html")
```

- 템플릿을 고쳤다면 **템플릿 셀 → 아래 셀** 순서로 둘 다 다시 실행해야 바뀐 내용이 반영됩니다.
- 미리보기가 그대로라면: 셀을 다시 실행하거나, 미리보기 안에서 마우스 오른쪽 → **새로고침**.

### 6-3. 단계별 확인 포인트

| 단계 | 미리보기에서 확인할 것 | 해 볼 것 (셀 끝 주석 참고) |
|------|------------------------|---------------------------|
| Step 2 | 첫날 발표가 카드로 나열되는가 | 발표 수 표시, 세션 코드 표시 |
| Step 3 | 날짜·장소 칩을 누르면 목록이 바뀌는가, 검색어가 노란색으로 표시되는가 | 세션 코드로 거르는 칩 추가 |
| Step 4 | ☆ 를 누르면 ★ 로 바뀌고 **내 일정** 탭에 모이는가, 겹치는 발표가 표시되는가 | 겹치는 발표 흐리게 표시 |

## 8. ⚠️ 주의할 점

### 8-1. Colab 사용

- **항상 사본에서 작업.** 원본 노트북은 보기 전용입니다. (§1)
- **런타임이 끊기면 파일이 사라집니다.** 90분 정도 아무것도 안 하거나, 창을 오래 닫아 두면 런타임이 초기화되어
  업로드한 `conference.json` 과 만든 HTML 이 모두 지워집니다(노트북 셀 내용은 남음).
  → 메뉴 **런타임 → 이전 셀 모두 실행**(또는 위에서부터 차례로 실행)으로 복구합니다. 데이터는 다시 업로드.
  → 결과물은 바로바로 `download()` 하거나 드라이브에 저장해 두세요.
- **셀은 위에서부터 순서대로.** "준비" 셀을 건너뛰면 `build is not defined` 같은 오류가 납니다.
- **실행 중인 셀(◼ 표시)이 있으면 다른 셀이 기다립니다.** 멈춘 것 같으면 ◼ 를 눌러 중지.
- Colab 의 **AI 자동완성/코드 생성**(Gemini) 사용 여부는 강사 안내를 따릅니다.

### 8-2. 템플릿 셀 편집

- `%%writefile` 첫 줄, `__DATA__` 자리는 건드리지 않습니다. (§6-1)
- JS 는 한 글자 실수로 **화면 전체가 하얗게** 될 수 있습니다. 흔한 실수:
  - 템플릿 문자열의 **백틱(`` ` ``)** 을 따옴표(`'`)로 잘못 씀, 또는 닫는 백틱 누락
  - `${ … }` 의 중괄호 짝이 안 맞음
  - 괄호 `( )`, `{ }` 짝이 안 맞음, 세미콜론 대신 쉼표
- 데이터를 화면에 넣을 때는 **`esc()` 로 감싸기.** 제목에 `<`, `&` 가 들어 있으면 화면이 깨집니다.
- 고치다 망가졌으면: 셀 내용을 **Ctrl+Z** 로 되돌리거나, 원본 노트북에서 해당 셀을 다시 복사해 옵니다.

### 8-3. 오류 찾기 — 개발자 도구

화면이 하얗거나 버튼이 반응하지 않으면, **내려받은 파일을 Chrome 으로 열고 `F12`** → **Console** 탭을 봅니다.
빨간 글씨의 오류 메시지와 줄 번호가 원인을 알려 줍니다.

| 오류 메시지 예 | 뜻 |
|----------------|-----|
| `Uncaught SyntaxError: Unexpected token` | 괄호·따옴표·백틱 짝이 안 맞음 |
| `… is not defined` | 이름 오타, 또는 정의 전에 사용 |
| `Cannot read properties of null` | `getElementById("…")` 의 id 가 HTML 에 없음 |
| `Unexpected identifier '__DATA__'` | `build()` 를 거치지 않은 템플릿 파일을 열었음 |

> Colab 미리보기 안에서도 마우스 오른쪽 → **검사** 로 콘솔을 볼 수 있지만, 내려받은 파일에서 보는 쪽이 정확합니다.

### 8-4. 다운로드

- **Chrome 권장.** Safari·일부 브라우저에서는 `download()` 가 아무 반응이 없을 수 있습니다.
- 처음 다운로드할 때 "**여러 파일 다운로드 허용**" 창이 뜨면 **허용**.
- `download()` 가 안 되면: 왼쪽 📁 파일 패널 → 파일에 마우스 오른쪽(또는 ⋮) → **다운로드**.
- 같은 이름으로 여러 번 받으면 `out_step5 (1).html`, `(2)` … 로 쌓입니다. **가장 최근 파일을 열고 있는지** 확인하세요.
- 학교·회사 PC 는 보안 정책으로 다운로드나 로컬 HTML 실행이 막혀 있을 수 있습니다 → 강사에게 알리기.

### 8-5. 내 PC 에서 쓸 때 (북마크 저장)

- 북마크는 **그 PC 의 그 브라우저**에만 저장됩니다(`localStorage`). 다른 PC·다른 브라우저에서 열면 비어 있습니다.
  → 옮기려면 완성본의 **⬇ 내보내기 → ⬆ 불러오기** 를 쓰세요.
- **시크릿(InPrivate) 창**에서 열면 창을 닫을 때 북마크가 사라집니다.
- Chrome 은 내 PC 의 HTML 파일들이 **저장 공간을 함께 씁니다.** 그래서 Step 4 에서 한 북마크가 Step 5 파일에서도
  보일 수 있습니다 — 고장이 아니라 정상입니다.
- Colab **미리보기의 북마크와 내려받은 파일의 북마크는 별개**입니다.
- 브라우저의 "인터넷 사용 기록 삭제(쿠키 및 사이트 데이터)" 를 하면 북마크가 지워집니다.
- **휴대폰으로 파일을 옮겨 열면** 파일 앱의 미리보기에서는 JS 가 동작하지 않거나 북마크가 저장되지 않을 수 있습니다.

### 8-6. 데이터·결과물 공유

- 만든 HTML 파일에는 **초록 본문을 포함한 데이터 전체가 들어 있습니다.**
  파일을 공유하면 데이터를 공유하는 것과 같습니다.
- 실습 데이터는 **수업용**입니다. 웹사이트·GitHub·SNS 등 **공개된 곳에 올리지 마세요.**

## 9. 문제 해결 빠른 표

| 증상 | 확인할 것 |
|------|-----------|
| `NameError: name 'build' is not defined` | 준비 셀을 실행했나? 런타임이 초기화됐나? (§8-1) |
| `FileNotFoundError: conference.json` | 데이터를 업로드했나? 런타임 초기화로 지워졌나? |
| `build()` 가 `__DATA__` 오류 | 템플릿에서 `__DATA__` 를 지웠거나 두 번 썼음 |
| 미리보기가 안 바뀜 | 템플릿 셀부터 다시 실행했나? 미리보기 새로고침 |
| 미리보기 자리가 비어 있음 | 셀 다시 실행. 그래도 안 되면 `download()` 해서 PC 에서 확인 |
| 내려받은 화면이 하얗다 | `F12` → Console 오류 확인 (§8-3) |
| 북마크가 사라졌다 | 시크릿 창? 다른 브라우저? 기록 삭제? (§8-5) |
| 다운로드가 안 된다 | Chrome? 다운로드 허용? 파일 패널에서 직접 받기 (§8-4) |

## 10. 과제 아이디어

난이도 순서입니다. 완성본(Step 5) 템플릿을 고쳐서 해 보세요.

1. 첫 화면 위쪽에 "총 발표 N건 · 세션 M개" 요약 표시
2. 발표 카드에 세션 제목을 마우스를 올렸을 때 보이게(`title` 속성)
3. 내 일정에서 북마크 개수를 탭 이름 옆에 배지로 표시
4. 다크 모드 버튼 (CSS 변수 바꾸기)
5. 내 일정을 **인쇄용**으로 깔끔하게 (`@media print`)
6. 키워드 구름: 초록 키워드를 많이 나온 순서로 모아 보여 주고, 누르면 검색
7. 내 일정을 캘린더 파일(`.ics`)로 내보내기
