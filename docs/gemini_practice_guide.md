# Gemini 와 함께 학회 시간표 앱 만들기 — 학생용 실습 안내서

Google Colab 옆의 **Gemini** 에게 말로 부탁하면서, 학회 발표 데이터(JSON)로
**내 PC 브라우저에서 쓰는 학회 시간표 앱(HTML 파일 하나)** 을 만드는 실습입니다.
코드를 직접 다 짜는 것이 아니라, **원하는 것을 정확히 설명하고, 결과를 확인하고, 고쳐 달라고 하는 과정**을 연습합니다.

---

## 1. 무엇을 만드나 — 완성 기준

아래를 모두 만족하면 성공입니다. 실습 내내 이 표를 옆에 두고 확인하세요.

**꼭 되어야 하는 것**

| # | 기준 | 확인 방법 |
|---|------|-----------|
| 1 | **HTML 파일 하나**로 동작한다 (다른 파일·서버 필요 없음) | 다운로드 폴더의 그 파일 하나만 다른 폴더로 옮겨 열어도 동작 |
| 2 | **인터넷 없이** 열린다 | Wi-Fi 를 끄고 열어 봐도 화면이 정상 |
| 3 | 날짜별로 발표를 볼 수 있다 | 날짜를 바꾸면 목록이 바뀜 |
| 4 | 발표장(룸)별로 볼 수 있다 | 동시에 열리는 발표장을 골라 볼 수 있음 |
| 5 | 제목·저자로 **검색**된다 | 아는 저자 이름을 넣어 보기 |
| 6 | 발표를 **북마크(☆)** 할 수 있다 | |
| 7 | 북마크한 발표가 **내 일정**에 시간순으로 모인다 | 날짜별·시간순인지 |
| 8 | 브라우저를 **닫았다 다시 열어도 북마크가 남아 있다** | 탭을 닫고 파일을 다시 열기 |
| 9 | **시간이 겹치는 북마크**를 알려 준다 | 같은 시간 다른 발표장 발표 두 개를 북마크 |

**더 하면 좋은 것** — 발표를 누르면 상세 정보, 세션별 보기, 휴대폰 화면에 맞는 디자인,
북마크 내보내기/불러오기, 오늘 날짜 자동 선택, 인쇄용 내 일정 …

## 2. 준비

| 준비물 | 비고 |
|--------|------|
| **개인 Google 계정** | 학교·회사 계정은 Gemini 가 꺼져 있을 수 있습니다 (§7-1) |
| PC + **Chrome** | 휴대폰·태블릿은 비권장 |
| 데이터 파일 `conference.json` | 강사가 배포 |

1. https://colab.research.google.com → **새 노트북**.
2. 노트북 이름을 바꿉니다 (예: `학회앱_홍길동.ipynb`). 노트북은 내 드라이브의 `Colab Notebooks` 폴더에 저장됩니다.
3. 화면 **맨 아래 가운데의 파란 동그라미 ✦ 버튼**(마우스를 올리면 **Toggle Gemini**)을 눌러 Gemini 패널을 엽니다.
   새 노트북을 열면 Gemini 패널이 **닫혀 있는 것이 기본**이라 처음엔 안 보입니다. 다시 누르면 닫힙니다.
   버튼이 아예 없으면 §7-1.
4. 데이터 파일을 런타임에 올립니다. 둘 중 하나:
   - **업로드**: 왼쪽 📁 파일 패널 → 업로드 버튼 → `conference.json`
     (또는 Gemini 에게 "파일 업로드하는 셀 만들어 줘")
   - **드라이브**: 드라이브에 `conference.json` 을 넣어 두고 Gemini 에게 "드라이브 연결해서 이 파일 읽는 코드 만들어 줘"
     (권한 창에서 허용)

> ⚠️ 업로드한 파일은 **런타임이 끊기면 사라집니다.** 오래 쉬었다 오면 다시 올려야 합니다(§7-2).

## 3. 작업하는 방법 — 한 바퀴 돌리기

```
① 원하는 것을 Gemini 에게 말한다
② Gemini 가 준 코드를 읽어 보고 셀에 넣어 실행한다
③ 결과 HTML 을 미리보기 / 다운로드해서 브라우저로 열어 본다
④ 완성 기준(§1)과 비교 → 안 되는 점을 구체적으로 다시 말한다
```

이 바퀴를 여러 번 돕니다. **한 번에 다 만들어 달라고 하지 마세요.** 작은 단계로 나눌수록 잘 됩니다.

## 4. 단계별 진행 — 프롬프트 예시

아래 프롬프트는 **예시**입니다. 그대로 복사하기보다 자기 말로 바꿔 쓰고, 결과를 보며 덧붙이세요.

### 단계 0. 목표 알려 주기

첫 대화에서 전체 그림과 **지켜야 할 조건**을 알려 둡니다. 이 조건이 가장 중요합니다.

> 학회 발표 일정 데이터(conference.json)로 학회 시간표 웹앱을 만들려고 해.
> 결과물은 **HTML 파일 하나**여야 하고, 다운로드해서 **인터넷 없이 더블클릭으로** 열 수 있어야 해.
> 그래서 데이터는 HTML 안에 넣어야 하고, 서버·fetch·외부 라이브러리(CDN)는 쓰지 마.
> 단계별로 같이 만들 거니까 우선 데이터부터 살펴보자.

### 단계 1. 데이터 구조 파악

> 업로드한 conference.json 을 읽어서 구조를 보여 주는 코드를 만들어 줘.
> 최상위 키, 각 목록의 개수, 첫 번째 항목 예시를 출력해 줘.

- 실행 결과를 **직접 보고** 어떤 필드가 있는지 확인하세요. (발표 목록, 날짜, 시작·끝 시각, 발표장, 제목, 저자 …)
- Gemini 가 필드 이름을 **지어내는** 일이 많습니다. 결과에 나온 실제 이름을 다음 프롬프트에 적어 주면 정확해집니다.

> 날짜별, 발표장별 발표 수를 표로 보여 줘.

### 단계 2. 첫 화면 — 발표 목록

> talks 의 발표들을 카드 목록으로 보여 주는 HTML 파일을 만들어 줘.
> 각 카드에는 시작–끝 시각, 발표장, 제목, 제1저자를 표시해.
> 데이터는 HTML 안의 &lt;script&gt; 에 넣고, 파일 이름은 app_v1.html 로 저장한 뒤
> Colab 안에서 미리보기, 그리고 다운로드하는 코드도 같이 줘.

- 다운로드한 파일을 **더블클릭해서 브라우저로** 열어 보세요. Colab 미리보기만으로 끝내지 마세요.

### 단계 3. 날짜·발표장 고르기, 검색

> 기존 기능은 그대로 두고, 위쪽에 날짜 버튼과 발표장 버튼을 추가해 줘.
> 누르면 그 날짜·발표장 발표만 보이게. 그리고 제목·저자 검색창도 넣어 줘. 파일은 app_v2.html.

### 단계 4. 북마크와 내 일정

> 각 발표에 ☆ 버튼을 달아서 북마크할 수 있게 해 줘. 북마크는 localStorage 에 저장해서
> 브라우저를 닫았다 열어도 남아 있어야 해.
> "내 일정" 탭을 만들어서 북마크한 발표를 날짜별·시간순으로 보여 주고,
> 시간이 겹치는 발표는 빨간색으로 표시해 줘. 파일은 app_v3.html.

- 겹침 확인: 같은 시간대 서로 다른 발표장의 발표 두 개를 북마크해 보세요.

### 단계 5. 다듬기 (자유)

자기 앱을 써 보면서 불편한 점을 고쳐 달라고 하세요. 예:

> 발표를 누르면 상세 화면이 나오게 해 줘. 같은 세션의 다른 발표 목록도 보여 줘.

> 휴대폰 화면에서도 보기 좋게 바꿔 줘. 아래쪽에 탭 메뉴를 두고 싶어.

> 내 일정을 JSON 파일로 내보내고 다시 불러오는 버튼을 만들어 줘.

## 5. 프롬프트 잘 쓰는 법

| 이렇게 | 대신 이렇게 하지 말기 |
|--------|----------------------|
| "날짜 버튼을 누르면 **그 날짜 발표만** 보이게 해 줘" | "필터 기능 넣어 줘" |
| "**기존 기능은 그대로 두고** 검색창만 추가해 줘" | "검색 기능 추가해 줘" (다른 기능이 사라지기도 함) |
| "북마크를 눌러도 내 일정에 안 나와. 콘솔 오류는 `…`" | "안 돼" |
| 실제 필드 이름을 적기 (`time_start`, `room`) | "시간", "장소" 만 쓰기 |
| 결과 파일을 **버전별 이름**으로 (`app_v1`, `app_v2` …) | 같은 이름에 계속 덮어쓰기 |

- 대화가 길어지면 Gemini 가 앞의 조건을 잊습니다. 이상해지면 **새 대화**를 열고 단계 0 의 조건과
  지금까지 만든 기능을 요약해서 다시 알려 주세요.
- Gemini 가 준 코드는 **실행 전에 훑어보세요.** 무엇을 하는 코드인지 모르겠으면 "이 코드 설명해 줘".
- 학생마다 결과가 다른 것이 정상입니다. 완성 기준(§1)을 만족하면 됩니다.

## 6. 결과 확인하기

1. 다운로드 폴더의 HTML 파일을 **더블클릭** → Chrome 에서 열림. 주소창이 `file:///…` 로 시작하면 정상.

   (Gemini 는 내 브라우저 화면을 볼 수 없습니다. Colab 셀 오류와 달리 브라우저 오류는 직접 전달해야 합니다.)

## 7. ⚠️ 주의할 점

### 7-1. Gemini 사용

**Gemini 패널이 안 보이면**

- **먼저 화면 맨 아래 가운데의 파란 ✦ 버튼(Toggle Gemini)을 누르세요.** 패널은 처음에 닫혀 있습니다.
  셀 안의 "generate with AI" 링크로도 열 수 있습니다.
- 그 버튼 자체가 없으면:
  - **계정 나이 18세 이상**, **지원 지역**이어야 Colab 의 AI 기능이 나옵니다.
  - **학교·회사(Workspace) 계정**은 관리자가 꺼 두었을 수 있습니다 → **개인 Gmail** 로 로그인한 창에서 다시 열기.
    (오른쪽 위 프로필 사진이 어느 계정인지 확인. 여러 계정이 로그인돼 있으면 다른 계정으로 열려 있기 쉽습니다.)
  - 새로고침(`F5`), 시크릿 창에서 개인 계정으로 열기, 광고 차단 확장 프로그램 끄기.
  - 그래도 안 되면 강사에게 알리고 짝과 함께 진행합니다. (Colab 쪽 일시적 오류일 수도 있습니다.)

**그 밖에**

- **사용량 제한**: 무료 계정은 일정 시간 동안 쓸 수 있는 횟수에 한도가 있습니다. 짧은 질문을 자주 보내기보다
  요구사항을 모아 한 번에 정확히 보내세요.
- **데이터를 채팅창에 붙여 넣지 마세요.** 파일이 커서 잘리고, Gemini 가 일부만 보고 판단합니다.
  파일은 런타임에 올리고, "코드로 읽어서 확인해 줘" 라고 하세요.
- Gemini 는 그럴듯한 **틀린 답**을 자신 있게 줄 수 있습니다. 항상 실행 결과로 확인하세요.

### 7-2. Colab 런타임

- **런타임이 끊기면 업로드 파일과 만든 HTML 이 사라집니다** (노트북 셀은 남음).
  → 데이터를 다시 올리고, 메뉴 **런타임 → 이전 셀 모두 실행** 으로 복구.
  → 잘 된 버전은 바로 다운로드하거나 드라이브에 저장.
- 셀은 **위에서부터 순서대로** 실행되어야 합니다. 중간 셀만 실행하면 `… is not defined` 오류가 납니다.

### 7-3. Gemini 가 자주 하는 실수 — 이런 결과가 나오면 다시 요청

| 증상 | 원인 | 이렇게 다시 요청 |
|------|------|------------------|
| 다운로드한 파일을 열면 **목록이 비어 있음** (Colab 미리보기에서는 됨) | HTML 이 `fetch("conference.json")` 로 데이터를 따로 읽음. 내 PC 에선 막힘 | "데이터를 HTML 안에 직접 넣어 줘. fetch 쓰지 마" |
| **인터넷을 끄면 디자인이 깨짐** | Bootstrap 등 외부 CDN 사용 | "외부 라이브러리 없이 CSS 를 직접 써 줘" |
| Flask, Streamlit, `localhost` 가 나옴 | 서버 앱으로 만듦 | "서버 없이 HTML 파일 하나로" |
| 파이썬에서 `KeyError`, `SyntaxError` (f-string) | HTML/JS 를 파이썬 f-string 에 넣으면 JS 의 `{ }` 와 충돌 | "HTML 은 따로 템플릿으로 쓰고, 데이터 자리만 문자열 치환으로 넣어 줘" |
| 화면이 갑자기 하얗게 + 콘솔에 `Unexpected token` | 데이터에 `</script>` 같은 글자가 있으면 스크립트가 끊김 | "데이터를 넣을 때 `</` 를 이스케이프해 줘" |
| 새 기능을 넣었더니 **예전 기능이 사라짐** | 코드를 처음부터 다시 쓰면서 빠뜨림 | "기존 기능을 모두 유지해. 바꾼 부분만 알려 줘" |
| 제목에 `<` 가 있으면 화면이 깨짐 | 이스케이프 없이 innerHTML 에 넣음 | "글자를 HTML 에 넣을 때 이스케이프해 줘" |
| 시간 정렬이 이상함 (`9:00` 이 `10:00` 뒤) | 시각을 문자열로 비교 | "시각을 분 단위 숫자로 바꿔서 비교해 줘" |
| 존재하지 않는 필드(`speaker`, `location` …) 사용 | 필드 이름을 추측 | 단계 1 에서 본 실제 필드 이름을 알려 주기 |

### 7-4. 다운로드와 북마크

- **Chrome 권장.** 처음 다운로드할 때 "여러 파일 다운로드 허용" 이 뜨면 허용.
  다운로드가 안 되면 왼쪽 📁 파일 패널에서 파일 오른쪽 클릭(⋮) → 다운로드.
- 같은 이름으로 여러 번 받으면 `app (1).html` 처럼 쌓입니다. **최신 파일을 열고 있는지** 확인.
- 북마크는 **그 PC 의 그 브라우저**에만 저장됩니다. 시크릿 창은 닫으면 사라집니다.
- Chrome 에서는 내 PC 의 HTML 파일들이 저장 공간을 함께 쓰므로, v2 에서 한 북마크가 v3 에서 보일 수 있습니다(정상).
- Colab 미리보기의 북마크와 다운로드한 파일의 북마크는 **별개**입니다.

### 7-5. 데이터·결과물

- 만든 HTML 에는 **데이터 전체가 들어 있습니다.** 파일 공유 = 데이터 공유입니다.
- 실습 데이터는 **수업용**입니다. 웹사이트·GitHub·SNS 등 공개된 곳에 올리지 마세요.
