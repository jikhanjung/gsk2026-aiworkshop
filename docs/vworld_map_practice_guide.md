# Gemini 와 함께 브이월드 지도 앱 만들기 — 학생용 실습 안내서

Google Colab 옆의 **Gemini** 에게 말로 부탁하면서, **브이월드(VWorld) 배경지도** 위에 내가 찍은 지점(답사지, 시료 채취 지점 …)을
기록하는 **지도 앱(HTML 파일 하나)** 을 만드는 실습입니다.
워크숍의 **첫 번째 실습**입니다. Gemini 에게 단계별로 요청하고, 결과를 확인하고, 고쳐 달라고 하는 방법을 여기서 익힙니다.
그와 함께 **외부 서비스의 API 인증키**를 발급받아 안전하게 쓰는 방법도 배웁니다.
(두 번째 실습인 Conference Organizer — `conference_organizer_practice_guide.md` — 도 같은 방식으로 진행합니다.)

## 1. 무엇을 만드나 — 완성 기준

**꼭 되어야 하는 것**

| # | 기준 | 확인 방법 |
|---|------|-----------|
| 1 | **HTML 파일 하나**로 동작한다 | 다운로드한 파일 하나만 다른 폴더로 옮겨 열어도 동작 |
| 2 | **내 인증키로 브이월드 배경지도**가 보이고, 처음 열면 대한민국 전체가 보인다 | 확대·이동해 보기 |
| 3 | 배경지도를 **바꿀 수 있다** (기본 / 위성 / 위성+지명 등) | 지도 오른쪽 위 메뉴 |
| 4 | 지도를 **클릭하면 그 자리에 지점을 추가**하고 이름·메모를 입력할 수 있다 | |
| 5 | 지점을 누르면 **입력한 정보와 좌표**가 보이고, **삭제**할 수 있다 | |
| 6 | 브라우저를 **닫았다 다시 열어도 지점이 남아 있다** | 탭을 닫고 파일을 다시 열기 |
| 7 | 지점 목록을 **파일로 내보내고 다시 불러올 수 있다** (JSON) | 내보낸 파일을 다른 브라우저에서 불러오기 |
| 8 | **인증키가 노트북 코드에 그대로 적혀 있지 않다** | 노트북을 공유해도 키가 보이지 않음 (§4 단계 1) |

> Conference Organizer 와 달리 이 앱은 **인터넷이 필요합니다.** 지도 그림(타일)을 브이월드 서버에서 받아 오기 때문입니다.
> 그래서 지도를 그려 주는 도구(예: Leaflet)도 인터넷에서 불러와 써도 됩니다. 어떤 도구를 쓸지는 Gemini 가 정합니다.

**더 하면 좋은 것** — 입력 항목(필드) 직접 정하기, 지점 목록 표 보기, 목록에서 누르면 그 지점으로 이동,
지점 종류별 색깔, 현재 위치 표시, **지질도 겹쳐 보기(§9, KIGAM 키 사전 발급 필요)**, 지도 타일이 안 불러지면 "인증키를 확인하세요" 안내, CSV 로 내보내기, 휴대폰 화면 대응 …

## 2. 준비

| 준비물 | 비고 |
|--------|------|
| **개인 Google 계정** | 학교·회사 계정은 Gemini 가 꺼져 있을 수 있습니다 (§7-1) |
| PC + **Chrome** | |
| **브이월드 회원가입 + 인증키** | **수업 전에 미리** 받아 오세요 (§2-1). 가입·메일 인증에 시간이 걸립니다 |

### 2-1. 브이월드 인증키 받기 (수업 전 과제)

1. https://www.vworld.kr 접속 → **회원가입** 후 로그인.
2. 위쪽 메뉴 **오픈API → 인증키 → 인증키 발급** (메뉴 이름은 바뀔 수 있습니다).
3. 신청 양식 작성:
   - 활용 목적·서비스명: 예) `수업 실습 - 답사 지점 지도`
   - **서비스 URL**: **강사가 알려 주는 값**을 그대로 적습니다. (지도를 어디서 열 것인지와 관계가 있어서, 강사가 미리 시험해 본 값을 씁니다.)
   - 사용할 API: **배경지도(WMTS)** 가 포함되도록 선택.
4. 가입할 때 쓴 **이메일로 온 인증 메일**에서 **인증키 사용** 버튼을 누릅니다.
   이걸 안 누르면 키가 동작하지 않습니다.
5. **인증키 관리** 메뉴에서 상태가 **승인**인지, **유효기간**이 언제까지인지 확인합니다.
6. 인증키(영문·숫자로 된 긴 문자열)를 복사해 둡니다.

> ⚠️ 인증키는 **비밀번호처럼** 다룹니다. 채팅방·게시판·GitHub 에 올리지 마세요. 남이 내 키로 사용량을 다 써 버릴 수 있습니다.

### 2-2. Colab 준비

1. https://colab.research.google.com → **새 노트북**, 이름 바꾸기 (예: `지도앱_홍길동.ipynb`).
2. 화면 **맨 아래 가운데의 파란 동그라미 ✦ 버튼**(마우스를 올리면 **Toggle Gemini**)을 눌러 Gemini 패널을 엽니다.
   새 노트북을 열면 Gemini 패널이 **닫혀 있는 것이 기본**이라 처음엔 안 보입니다. 다시 누르면 닫힙니다.
   버튼이 아예 없으면 §7-1.

## 3. 작업하는 방법 — 한 바퀴 돌리기

```
① 원하는 것을 Gemini 에게 말한다
② Gemini 가 준 코드를 읽어 보고 셀에 넣어 실행한다
③ 결과 HTML 을 다운로드해서 브라우저로 열어 본다   ← 지도 앱은 꼭 다운로드한 파일로 확인 (§7-3)
④ 완성 기준(§1)과 비교 → 안 되는 점을 구체적으로 다시 말한다
```

**한 번에 다 만들어 달라고 하지 마세요.** 지도 → 배경 바꾸기 → 지점 추가 → 저장 → 내보내기 순으로 하나씩.

## 4. 단계별 진행 — 프롬프트 예시

예시는 **참고용**입니다. 자기 말로 바꾸고, 결과를 보며 덧붙이세요.

> **프로그래밍 용어를 몰라도 됩니다.** Gemini 에게는 ① **무엇을 하고 싶은지** ② **화면이 어떻게 보이면 좋겠는지**
> ③ **어떻게 확인할 건지**를 평소 말로 설명하세요. 어떤 기술을 쓸지는 Gemini 가 고릅니다.
> 다만 **지켜야 할 조건**(파일 하나, 더블클릭으로 열기, 인증키 안 보이게)은 처음에 꼭 말해 두세요.
> Gemini 가 브이월드 지도 주소처럼 **정확한 정보를 몰라 헤맬 때만** 아래 §4-1 참고 카드를 붙여 넣으면 됩니다.

### 단계 0. 하고 싶은 것과 조건 알려 주기

> 내 PC 에서 더블클릭으로 여는 **지도 프로그램**을 만들고 싶어. 답사 갔던 곳이나 시료를 채취한 곳을 지도에 찍어서 기록하려고.
> 지도는 국토교통부의 **브이월드** 지도를 쓰고 싶고, 브이월드 **인증키**는 받아 놨어.
> 조건은 이래:
> - 결과는 **파일 하나**였으면 좋겠어. 내려받아서 더블클릭하면 바로 열리게. 다른 프로그램을 설치하거나 켜 둘 필요 없이.
> - 인터넷은 연결돼 있다고 생각해도 돼.
> - 인증키는 비밀번호 같은 거라서, 이 노트북을 다른 사람에게 보여 줘도 **키가 안 보이게** 하고 싶어.
>
> 나는 프로그래밍을 잘 몰라. 한 번에 다 만들지 말고 단계별로 같이 하자.
> 단계마다 내가 뭘 하면 되는지(어떤 셀을 실행하고, 무엇을 확인하는지)도 알려 줘.

- Gemini 가 쓰는 말 중 모르는 게 있으면 바로 물어보세요: "○○가 뭐야? 쉽게 설명해 줘."

### 단계 1. 인증키를 안전하게 넣고, 동작하는지 확인

먼저 Gemini 에게 키를 어디에 두면 되는지 물어봅니다.

> 인증키를 노트북에 직접 적지 않고 안전하게 넣어 두려면 어떻게 해야 해?

Gemini 는 Colab 의 **보안 비밀(Secrets)** 기능을 알려 줄 겁니다. 순서는 이렇습니다.

1. Colab **왼쪽 세로 아이콘 줄의 열쇠(🔑, 보안 비밀 / Secrets)** 아이콘 → **새 보안 비밀 추가** →
   이름 `VWORLD_KEY`, 값에 인증키 붙여 넣기 → **노트북 액세스** 켜기.
2. 그다음 Gemini 에게:

> 보안 비밀에 `VWORLD_KEY` 라는 이름으로 인증키를 넣었어.
> 이 키가 제대로 되는지 먼저 시험해 보고 싶어. 브이월드에서 **지도 그림 한 장**만 받아 와서,
> 잘 받아지면 "성공", 아니면 무엇 때문에 실패했는지 알려 줘. **키는 화면에 보이지 않게** 해 줘.

- "성공" 이 나오면 키가 동작합니다. 실패하면 나온 문구를 읽어 보세요 (§7-2).
- Gemini 가 주소를 몰라 계속 실패하면 **§4-1 참고 카드 A** 를 붙여 넣으세요.
- 왜 보안 비밀을 쓰나요? 노트북을 공유하거나 제출하면 **셀에 적힌 글자는 모두 보입니다.** 보안 비밀은 노트북 파일에 저장되지 않습니다.

### 단계 2. 첫 지도

> 키가 잘 되네. 이제 실제 지도 화면을 만들어 줘.
> 열면 **우리나라 전체**가 보이고, 마우스로 확대·축소하고 끌어서 옮길 수 있으면 돼. 지도가 **창 전체**를 채웠으면 좋겠어.
> 결과는 내 PC 로 내려받을 수 있는 파일 `map_v1.html` 로 만들어 줘.

- 내려받은 파일을 **더블클릭**해서 지도가 나오는지 보세요.
- 하얗거나, 회색이거나, 조각조각 흩어지면 **보이는 그대로** Gemini 에게 말하세요 (§7-3).

### 단계 3. 배경지도 바꾸기

> 지금 되는 건 그대로 두고, **배경지도를 바꿔 볼 수 있게** 해 줘.
> 일반 지도, **항공사진**, 항공사진 위에 **지명·도로**가 같이 나오는 지도, 흰 바탕 지도 정도면 좋겠어.
> 화면 구석에 고르는 메뉴가 있으면 돼. 파일은 `map_v2.html`.

- 항공사진이 안 나오거나 지명만 나오면 보이는 대로 말하고, 그래도 안 되면 참고 카드 A 를 붙여 넣으세요.

### 단계 4. 지점 찍기 · 보기 · 지우기 · 남겨 두기

> 이제 기록 기능을 넣고 싶어. 지금 되는 건 그대로 두고:
> - 지도에서 한 곳을 **클릭하면 거기에 핀**을 꽂고, 그 지점의 **이름과 메모**를 적을 수 있게 해 줘.
> - 나중에 핀을 누르면 적은 내용과 **위치(위도·경도)** 가 보이고, **지울** 수도 있게.
> - 프로그램을 **껐다 켜도** 찍어 둔 지점이 그대로 남아 있어야 해.
>
> 파일은 `map_v3.html`.

- 확인: 지점 3개를 찍고 → 탭을 닫고 → 파일을 다시 열기.
- 이름 칸에 `<b>굵게</b>` 라고 입력해 보세요. **글자 그대로** 보여야 정상입니다.
  굵게 나오면: "이름 칸에 `<b>굵게</b>` 라고 썼더니 글자가 굵게 나와. 내가 쓴 글자가 **그대로** 보이게 해 줘.
  이상한 글자를 넣어도 화면이 망가지지 않게." (왜 중요한지 궁금하면 Gemini 에게 물어보세요.)

### 단계 5. 파일로 저장하고 다시 불러오기

> 찍어 둔 지점들을 **파일로 저장**해서 다른 컴퓨터로 옮기고 싶어.
> 저장 버튼과 불러오기 버튼을 만들어 줘. 불러올 때 지금 있는 지점을 **지울지, 합칠지** 물어봐 줘.
> 파일은 `map_v4.html`.

- 저장한 파일을 **다른 브라우저(또는 시크릿 창)** 에서 불러와 보세요.

### 단계 6. 다듬기 (자유)

직접 써 보면서 불편한 점을 말하세요. 예:

> 답사 기록용으로 쓰고 싶어. 지점마다 적는 칸을 **내가 정할 수 있게** 해 줘 (예: 지점명, 암석 종류, 주향/경사, 날짜, 메모).

> 화면 왼쪽에 지점 목록을 보여 주고, 목록에서 누르면 지도가 그 지점으로 이동하게 해 줘.

> 지도가 안 나올 때 그냥 회색으로 두지 말고, "인증키를 확인하세요" 처럼 **이유를 화면에 알려** 줘.

### 4-1. 참고 카드 — Gemini 가 헤맬 때 붙여 넣을 정보

**내용을 이해하지 않아도 됩니다.** Gemini 가 브이월드 지도 주소를 지어내서 계속 실패할 때, 아래 상자를 그대로 복사해 붙여 넣으세요.

**참고 카드 A — 브이월드 배경지도**

```
브이월드 배경지도 정보야. 이대로 써 줘.
- 지도 그림(타일) 주소: https://api.vworld.kr/req/wmts/1.0.0/{인증키}/{레이어}/{z}/{y}/{x}.{확장자}
  (순서가 z, y, x 야. y 가 x 보다 먼저)
- 레이어와 확장자: Base(일반 지도, png), Satellite(항공사진, jpeg), Hybrid(지명·도로만 있는 투명한 그림, png — 항공사진 위에 겹쳐 써야 함),
  white(흰 바탕, png), midnight(어두운 바탕, png)
- 예: 줌 7, y=49, x=109 의 일반 지도 → https://api.vworld.kr/req/wmts/1.0.0/{인증키}/Base/7/49/109.png
- 키가 틀리면 그림 대신 "등록되지 않은 인증키입니다." 라는 글(XML)이 와.
- 지도는 Leaflet 으로 그리면 돼.
```

## 5. 프롬프트 잘 쓰는 법

**기술 용어 대신, 원하는 것과 본 것을 구체적으로.**

| 이렇게 | 대신 이렇게 하지 말기 |
|--------|----------------------|
| "지도를 클릭하면 **그 자리에 핀**을 꽂고 이름·메모를 적게 해 줘" | "마커 기능 넣어 줘" |
| **본 그대로** 말하기: "핀 하나를 지웠는데 **다른 핀**이 사라졌어" | "안 돼" |
| 오류가 나면 **빨간 글씨를 그대로 복사**해서 붙여 넣기 | "오류 났어" |
| "**지금 되는 건 그대로 두고** ○○만 추가해 줘" | 새 기능만 말하기 (예전 기능이 사라지기도 함) |
| 결과 파일을 **버전별 이름**으로 (`map_v1`, `map_v2` …) | 같은 이름에 계속 덮어쓰기 |
| "구글 지도 말고 **브이월드** 지도로" | "지도 넣어 줘" (다른 회사 지도를 쓰기도 함) |
| 모르는 말이 나오면 "○○가 뭐야? 쉽게 설명해 줘" | 모르는 채로 넘어가기 |
| 같은 실패가 반복되면 **참고 카드**(§4-1) 붙여 넣기 | 혼자 코드를 고쳐 보기 |
| 인증키는 **보안 비밀**에만 | 채팅창에 인증키를 붙여 넣기 |

- 대화가 길어지면 Gemini 가 앞의 조건을 잊습니다. 이상해지면 **새 대화**를 열고 단계 0 의 조건과

### 7-2. 인증키 문제

| 증상 | 원인 | 해결 |
|------|------|------|
| 응답에 `등록되지 않은 인증키입니다` | 키 오타, 앞뒤 공백, **메일 인증(인증키 사용) 안 누름** | 키를 다시 복사, 메일 확인, 인증키 관리에서 "승인" 확인 |
| 응답에 도메인/URL 이 맞지 않는다는 문구 (`INCORRECT_KEY` 등) | 신청할 때 적은 **서비스 URL** 과 지도를 연 곳이 다름 | 강사 안내 값으로 서비스 URL 수정 (인증키 관리에서 변경) |
| 어제는 됐는데 오늘 안 됨 | **유효기간 만료** 또는 사용량 초과 | 인증키 관리에서 기간 연장 |
| 보안 비밀을 못 읽음 (`SecretNotFoundError` 등) | 이름 오타, **노트북 액세스** 꺼짐 | 🔑 패널에서 이름 `VWORLD_KEY` 와 액세스 스위치 확인 |

- 인증키는 **만든 HTML 파일 안에 들어갑니다.** HTML 파일을 남에게 주면 키도 같이 주는 것입니다 (§7-5).

### 7-3. Gemini 가 자주 하는 실수 — 이런 결과가 나오면 다시 요청

"이렇게 말하기" 의 핵심은 **본 것을 그대로 설명하고, 오류 문구가 있으면 붙여 넣는 것**입니다. "왜 그런가" 칸은 몰라도 됩니다.

| 이런 일이 생기면 | 이렇게 말하기 | 왜 그런가 (몰라도 됨) |
|------------------|---------------|------------------------|
| 셀을 실행했더니 빨간 오류 (`NameError: name 'z' …`, `KeyError` 등) | "셀을 실행했더니 이런 오류가 나와: (오류 붙여 넣기)". 같은 오류가 반복되면 "화면 내용(HTML)은 파이썬 코드와 따로 두고, 키 들어갈 자리만 바꿔 넣는 식으로 해 줘" | 지도 주소의 `{z}/{y}/{x}` 를 파이썬이 자기 변수로 착각 (f-string) |
| 파일을 열면 지도 자리가 **완전히 하얗게** 비어 있음 | "지도 자리가 하얗게 비어 있어. 지도가 창 전체를 채우게 해 줘" | 지도 영역의 높이가 0 |
| 지도 조각이 **뒤죽박죽 흩어져** 보임 | "지도 조각들이 흩어져서 보여" | 지도 도구(Leaflet)의 모양 파일(CSS)을 안 불러옴 |
| 바탕이 **회색**이고 지도 그림이 안 나옴 | "지도가 회색으로만 나와" + F12 오류 붙여 넣기. 반복되면 **참고 카드 A** | 지도 주소 형식 오류(y·x 순서, 항공사진은 jpeg, 레이어 이름) 또는 인증키 문제 |
| 항공사진 위에 지명이 안 나옴 / 지명만 나오고 사진이 없음 | 본 대로 말하기 + 참고 카드 A | 지명 그림은 투명해서 항공사진 위에 겹쳐야 함 |
| 구글 지도·카카오맵 등 **다른 지도**가 나옴 | "다른 지도 말고 브이월드 지도로 해 줘" | 지도를 특정하지 않음 |
| 지도는 나오는데 **클릭해도 핀이 안 생김** (내려받은 파일에서) | "내려받은 파일에서 지도를 클릭해도 핀이 안 생겨. 파일만으로 클릭해서 기록할 수 있어야 해" | 파이썬 지도 도구(folium)로 만든 고정된 지도 |
| 노트북 셀에 **인증키가 그대로** 보임 | "노트북에 내 인증키가 보여. 다른 사람이 못 보게 보안 비밀에 두고 쓰게 해 줘" | 편하게 하려고 키를 코드에 적음 |
| 이름에 `<b>` 를 넣으면 **굵게** 보임 / 화면이 깨짐 | "내가 쓴 글자가 그대로 보이게 해 줘. 이상한 글자를 넣어도 화면이 망가지지 않게" | 입력한 글자를 화면 코드로 해석 (이스케이프 누락) |
| 핀 하나를 지웠는데 **다른 핀**이 지워짐 | "○○ 핀을 지웠는데 △△ 핀이 사라졌어" | 핀을 위치로만 구분 (고유 번호 없음) |
| 껐다 켜면 핀이 **다 사라짐** | "탭을 닫았다 다시 열면 핀이 다 없어져" — 먼저 시크릿 창이 아닌지 확인 | 저장 기능 누락, 또는 시크릿 창 |
| 새 기능을 넣었더니 **예전 기능이 사라짐** | "○○ 기능이 없어졌어. 전에 되던 기능은 모두 그대로 두고 고쳐 줘" | 코드를 처음부터 다시 쓰면서 빠뜨림 |
| Colab 미리보기에서는 지도가 안 나오는데 내려받은 파일은 됨 (또는 반대) | 요청하지 말고 **내려받은 파일 기준**으로 판단 | 미리보기는 Colab 주소에서 열려 키 검사에 걸릴 수 있음 |

## 9. (심화) 지질도 겹쳐 보기 — 한국지질자원연구원 지질도 오버레이

브이월드 배경지도 위에 **한국지질자원연구원(KIGAM)의 지질도**를 반투명하게 겹쳐, 내가 찍은 지점이 어떤 지층·암석 위에 있는지
볼 수 있습니다. 지질도는 KIGAM **지오빅데이터 오픈플랫폼**의 OpenAPI(WMS)로 받아 옵니다.

> ⚠️ **수업 당일에 바로 하기는 어렵습니다.** 회원가입은 바로 되지만, OpenAPI 인증키는 **신청 후 승인**을 받아야 해서
> 당일에 나오지 않을 수 있습니다(브이월드 키는 신청 즉시 발급).
> → 해 보고 싶은 학생은 **수업 며칠 전에 미리 신청**하거나, **수업 뒤 과제**로 합니다.
> 본 실습(§1~§8)의 완성 기준에는 들어가지 않습니다.

### 9-1. KIGAM 인증키 신청 (미리)

1. https://data.kigam.re.kr (지오빅데이터 오픈플랫폼) → **회원가입** 후 로그인.
2. **OpenAPI 신청** 메뉴(마이페이지 쪽, 주소 `https://data.kigam.re.kr/my-openapi/request/`)에서 신청서를 냅니다.
   활용 목적은 예) `수업 실습 - 답사 지점 지도에 지질도 오버레이`. (신청서 항목·메뉴 이름은 바뀔 수 있습니다.)
3. **승인 대기** → 승인되면 OpenAPI 메뉴에서 인증키를 확인합니다. 승인 여부는 사이트에서 직접 확인하세요.
4. 사용 방법 안내: https://data.kigam.re.kr/guide/openapi ,
   레이어 목록: https://data.kigam.re.kr/map/openapimanual/openapiLayerList.html
5. 문의: 한국지질자원연구원 지질자원데이터연구실 (042-868-3111).

> 인증키는 브이월드 키와 마찬가지로 **비밀번호처럼** 다룹니다. Colab 🔑 보안 비밀에 `KIGAM_KEY` 로 넣으세요.

### 9-2. 참고 카드 B — 지질도 정보 (Gemini 가 헤맬 때 붙여 넣기)

이해하지 않아도 됩니다. 9-3 의 요청에 Gemini 가 주소·방법을 몰라 헤매면 아래 상자를 그대로 붙여 넣으세요.

```
한국지질자원연구원 지질도 정보야. 이대로 써 줘.
- WMS 주소: https://data.kigam.re.kr/openapi/wms
- 인증키는 key 파라미터로 붙여 (key=발급받은키)
- 레이어: L_50K_Geology_Map (1:5만), L_250K_Geology_Map (1:25만), L_1M_Geology_Map (1:100만)
- 표준 WMS GetMap 요청: format=image/png, transparent=true
- Leaflet 에서는 L.tileLayer.wms 로 겹치면 돼.
```

알아 둘 것:
- **지나치게 잦은 호출은 이용이 제한될 수 있다**고 안내돼 있습니다. 지도를 마구 확대·이동하며 시험하지 마세요.
- 1:5만 지질도는 **도폭(지도 한 장 단위)이 없는 지역**은 비어 보일 수 있습니다. 그럴 땐 1:25만으로 바꿔 보세요.

### 9-3. 프롬프트 예시

> 지금 지도 위에 **한국지질자원연구원 지질도**를 반쯤 투명하게 겹쳐서, 내가 찍은 지점이 어떤 암석·지층 위에 있는지 보고 싶어.
> 지질자원연구원 인증키도 받아서 보안 비밀에 `KIGAM_KEY` 로 넣어 뒀어.
> 지질도를 켜고 끌 수 있게, 1:5만과 1:25만 중에 고를 수 있게 해 줘. 지금 되는 기능은 그대로 두고.
> 지질자원연구원 키가 없을 때는 지질도 메뉴 없이 예전처럼 동작하게 해 줘.

더 해 볼 것:

> 지질도가 너무 진해서 바탕 지도가 안 보여. 진하기를 내가 조절할 수 있게 해 줘.

> 핀을 찍을 때 그 자리가 어떤 암석·지층인지 지질도에서 알아내서 같이 적어 줄 수 있어? 안 되면 안 된다고 알려 줘.
