# Gemini 와 함께 브이월드 지도 앱 만들기 — 학생용 실습 안내서

Google Colab 옆의 **Gemini** 에게 말로 부탁하면서, **브이월드(VWorld) 배경지도** 위에 내가 찍은 지점(답사지, 시료 채취 지점 …)을
기록하는 **지도 앱(HTML 파일 하나)** 을 만드는 실습입니다.
학회 시간표 앱 실습(`gemini_practice_guide.md`)과 진행 방식은 같고, 이번에는 **외부 서비스의 API 인증키**를 발급받아
안전하게 쓰는 과정이 더해집니다.

---

## 1. 무엇을 만드나 — 완성 기준

**꼭 되어야 하는 것**

| # | 기준 | 확인 방법 |
|---|------|-----------|
| 1 | **HTML 파일 하나**로 동작한다 | 다운로드한 파일 하나만 다른 폴더로 옮겨 열어도 동작 |
| 2 | **내 인증키로 브이월드 배경지도**가 보이고, 처음 열면 대한민국 전체가 보인다 | 확대·이동해 보기 |
| 3 | 배경지도를 **바꿀 수 있다** (기본 / 위성 / 위성+지명 등) | 지도 오른쪽 위 메뉴 |
| 4 | 지도를 **클릭하면 그 자리에 지점을 추가**하고 이름·메모를 입력할 수 있다 | |
| 5 | 지점을 누르면 **입력한 정보와 좌표**가 보이고, **삭제**할 수 있다 | |
| 6 | 브라우저를 **닫았다 다시 열어도 지점이 남아 있다** | 탭을 닫고 파일을 다시 열기 |
| 7 | 지점 목록을 **파일로 내보내고 다시 불러올 수 있다** (JSON) | 내보낸 파일을 다른 브라우저에서 불러오기 |
| 8 | **인증키가 노트북 코드에 그대로 적혀 있지 않다** | 노트북을 공유해도 키가 보이지 않음 (§4 단계 1) |

> 학회 시간표 앱과 달리 이 앱은 **인터넷이 필요합니다.** 지도 그림(타일)을 브이월드 서버에서 받아 오기 때문입니다.
> 그래서 지도 라이브러리 **Leaflet** 은 CDN(인터넷 주소)으로 불러와도 됩니다.

**더 하면 좋은 것** — 입력 항목(필드) 직접 정하기, 지점 목록 표 보기, 목록에서 누르면 그 지점으로 이동,
지점 종류별 색깔, 현재 위치 표시, **지질도 겹쳐 보기(§9, KIGAM 키 사전 발급 필요)**, 지도 타일이 안 불러지면 "인증키를 확인하세요" 안내, CSV 로 내보내기, 휴대폰 화면 대응 …

## 2. 준비

| 준비물 | 비고 |
|--------|------|
| **개인 Google 계정** | 학교·회사 계정은 Gemini 가 꺼져 있을 수 있습니다 (§7-1) |
| PC + **Chrome** | |
| **브이월드 회원가입 + 인증키** | **수업 전에 미리** 받아 오세요 (§2-1). 가입·메일 인증에 시간이 걸립니다 |

### 2-1. 브이월드 인증키 받기 (수업 전 과제)

1. https://www.vworld.kr 접속 → **회원가입** 후 로그인.
2. 위쪽 메뉴 **오픈API → 인증키 → 인증키 발급** (메뉴 이름은 바뀔 수 있습니다).
3. 신청 양식 작성:
   - 활용 목적·서비스명: 예) `수업 실습 - 답사 지점 지도`
   - **서비스 URL**: **강사가 알려 주는 값**을 그대로 적습니다. (지도를 어디서 열 것인지와 관계가 있어서, 강사가 미리 시험해 본 값을 씁니다.)
   - 사용할 API: **배경지도(WMTS)** 가 포함되도록 선택.
4. 가입할 때 쓴 **이메일로 온 인증 메일**에서 **인증키 사용** 버튼을 누릅니다.
   이걸 안 누르면 키가 동작하지 않습니다.
5. **인증키 관리** 메뉴에서 상태가 **승인**인지, **유효기간**이 언제까지인지 확인합니다.
6. 인증키(영문·숫자로 된 긴 문자열)를 복사해 둡니다.

> ⚠️ 인증키는 **비밀번호처럼** 다룹니다. 채팅방·게시판·GitHub 에 올리지 마세요. 남이 내 키로 사용량을 다 써 버릴 수 있습니다.

### 2-2. Colab 준비

1. https://colab.research.google.com → **새 노트북**, 이름 바꾸기 (예: `지도앱_홍길동.ipynb`).
2. 화면 **맨 아래 가운데의 파란 동그라미 ✦ 버튼**(마우스를 올리면 **Toggle Gemini**)을 눌러 Gemini 패널을 엽니다.
   새 노트북을 열면 Gemini 패널이 **닫혀 있는 것이 기본**이라 처음엔 안 보입니다. 다시 누르면 닫힙니다.
   버튼이 아예 없으면 §7-1.

## 3. 작업하는 방법 — 한 바퀴 돌리기

```
① 원하는 것을 Gemini 에게 말한다
② Gemini 가 준 코드를 읽어 보고 셀에 넣어 실행한다
③ 결과 HTML 을 다운로드해서 브라우저로 열어 본다   ← 지도 앱은 꼭 다운로드한 파일로 확인 (§7-3)
④ 완성 기준(§1)과 비교 → 안 되는 점을 구체적으로 다시 말한다
```

**한 번에 다 만들어 달라고 하지 마세요.** 지도 → 배경 바꾸기 → 지점 추가 → 저장 → 내보내기 순으로 하나씩.

## 4. 단계별 진행 — 프롬프트 예시

예시는 **참고용**입니다. 자기 말로 바꾸고, 결과를 보며 덧붙이세요.

### 단계 0. 목표와 조건 알려 주기

> 브이월드 배경지도를 쓰는 지도 웹앱을 HTML 파일 하나로 만들려고 해.
> 지도 라이브러리는 **Leaflet**(CDN)을 쓰고, 배경지도는 **브이월드 WMTS** 를 내 인증키로 불러올 거야.
> 다운로드해서 더블클릭으로 열 수 있어야 하니까 서버(Flask 등)는 쓰지 마.
> 인증키는 **Colab 보안 비밀(Secrets)** 에 `VWORLD_KEY` 라는 이름으로 넣어 둘 테니, 코드에 직접 적지 말고 거기서 읽어서 써.
> 단계별로 같이 만들 거야.

### 단계 1. 인증키를 안전하게 넣고, 동작하는지 확인

1. Colab **왼쪽 세로 아이콘 줄의 열쇠(🔑, 보안 비밀 / Secrets)** 아이콘 → **새 보안 비밀 추가** → 이름 `VWORLD_KEY`, 값에 인증키 붙여 넣기 →
   **노트북 액세스** 켜기.
2. Gemini 에게:

> 보안 비밀의 VWORLD_KEY 를 읽어서, 브이월드 WMTS 기본지도 타일 하나를 요청해 보는 코드를 만들어 줘.
> 주소 형식은 `https://api.vworld.kr/req/wmts/1.0.0/{인증키}/Base/{z}/{y}/{x}.png` 야 (**y 가 x 보다 먼저**).
> z=7, y=49, x=109 로 요청해서, 응답이 이미지면 "성공", 아니면 응답 내용을 그대로 출력해 줘.
> 인증키는 출력하지 마.

- "성공" 이 나오면 키가 동작합니다. 실패하면 출력된 문구를 읽어 보세요 (§7-2).
- 왜 보안 비밀을 쓰나요? 노트북을 공유하거나 제출하면 **셀에 적힌 글자는 모두 보입니다.** 보안 비밀은 노트북 파일에 저장되지 않습니다.

### 단계 2. 첫 지도

> 이제 Leaflet 으로 브이월드 기본지도(Base)를 보여 주는 HTML 을 만들어 줘.
> 처음 화면은 대한민국 전체(위도 36.5, 경도 127.5, 줌 7). 지도는 화면 전체를 채우게.
> HTML 은 템플릿으로 따로 쓰고, 인증키가 들어갈 자리만 파이썬에서 문자열 치환으로 넣어 줘.
> 파일 이름은 map_v1.html, 다운로드하는 코드도 같이 줘.

- 다운로드한 파일을 **더블클릭**해서 지도가 나오는지 보세요.
- 지도가 회색이거나 조각조각 흩어지면 §7-3 표를 보세요.

### 단계 3. 배경지도 바꾸기

> 기존 기능은 그대로 두고, 오른쪽 위에 배경지도 선택 메뉴를 넣어 줘.
> 브이월드 레이어: 기본(Base, png), 위성(Satellite, **jpeg**), 위성 위에 지명·도로를 겹친 하이브리드(Hybrid, png 를 Satellite 위에 겹치기),
> 흰색(white, png), 야간(midnight, png). 파일은 map_v2.html.

### 단계 4. 지점 추가 · 정보 보기 · 삭제 · 저장

> 지도를 클릭하면 그 자리에 마커를 추가하고, 팝업에서 이름과 메모를 입력해 저장하게 해 줘.
> 마커를 누르면 이름·메모·위도·경도를 보여 주고 삭제 버튼도 있게.
> 마커들은 localStorage 에 저장해서 브라우저를 닫았다 열어도 남아 있어야 해.
> 입력한 글자는 HTML 에 넣을 때 이스케이프해 줘. 파일은 map_v3.html.

- 확인: 지점 3개를 찍고 → 탭을 닫고 → 파일을 다시 열기.
- 이름에 `<b>굵게</b>` 라고 입력해 보세요. **글자 그대로** 보여야 정상입니다 (§7-3).

### 단계 5. 내보내기 / 불러오기

> 지점 목록을 JSON 파일로 내보내는 버튼과, 그 파일을 불러오는 버튼을 위쪽에 만들어 줘.
> 불러올 때 기존 지점을 지울지, 합칠지 물어봐 줘. 파일은 map_v4.html.

- 내보낸 파일을 **다른 브라우저(또는 시크릿 창)** 에서 불러와 보세요.

### 단계 6. 다듬기 (자유)

> 입력 항목을 내가 정할 수 있게 해 줘 (예: 지점명, 암상, 주향/경사, 날짜, 메모).

> 왼쪽에 지점 목록을 보여 주고, 목록을 누르면 그 지점으로 이동하게 해 줘.

> 지도 타일을 못 불러오면 화면 위쪽에 "인증키를 확인하세요" 라고 알려 줘.

## 6. 결과 확인하기

1. 다운로드한 HTML 을 **더블클릭** → Chrome. 주소창이 `file:///…` 로 시작하면 정상.
2. §1 완성 기준을 하나씩 확인.
3. 지도가 안 나오거나 버튼이 안 되면 **`F12` → Console** (빨간 오류) 과 **Network** 탭(타일 요청이 빨간색인지)을 확인하고,
   오류 문구를 그대로 Gemini 에게 알려 주세요. **인증키가 포함된 주소는 지우고** 붙여 넣으세요.

## 7. ⚠️ 주의할 점

### 7-1. Gemini 버튼이 안 보일 때

- **먼저 화면 맨 아래 가운데의 파란 ✦ 버튼(Toggle Gemini)을 누르세요.** 패널은 처음에 닫혀 있습니다.
  셀 안의 "generate with AI" 링크로도 열 수 있습니다.
- 그 버튼 자체가 없으면:
  - **계정 나이 18세 이상**, **지원 지역**이어야 Colab 의 AI 기능이 나옵니다.
  - **학교·회사(Workspace) 계정**은 관리자가 꺼 두었을 수 있습니다 → **개인 Gmail** 로 로그인한 창에서 다시 열기.
    (오른쪽 위 프로필 사진이 어느 계정인지 확인. 여러 계정이 로그인돼 있으면 다른 계정으로 열려 있기 쉽습니다.)
  - 새로고침(`F5`), 시크릿 창에서 개인 계정으로 열기, 광고 차단 확장 프로그램 끄기.
  - 그래도 안 되면 강사에게 알리고 짝과 함께 진행합니다. (Colab 쪽 일시적 오류일 수도 있습니다.)

### 7-2. 인증키 문제

| 증상 | 원인 | 해결 |
|------|------|------|
| 응답에 `등록되지 않은 인증키입니다` | 키 오타, 앞뒤 공백, **메일 인증(인증키 사용) 안 누름** | 키를 다시 복사, 메일 확인, 인증키 관리에서 "승인" 확인 |
| 응답에 도메인/URL 이 맞지 않는다는 문구 (`INCORRECT_KEY` 등) | 신청할 때 적은 **서비스 URL** 과 지도를 연 곳이 다름 | 강사 안내 값으로 서비스 URL 수정 (인증키 관리에서 변경) |
| 어제는 됐는데 오늘 안 됨 | **유효기간 만료** 또는 사용량 초과 | 인증키 관리에서 기간 연장 |
| 보안 비밀을 못 읽음 (`SecretNotFoundError` 등) | 이름 오타, **노트북 액세스** 꺼짐 | 🔑 패널에서 이름 `VWORLD_KEY` 와 액세스 스위치 확인 |

- 인증키는 **만든 HTML 파일 안에 들어갑니다.** HTML 파일을 남에게 주면 키도 같이 주는 것입니다 (§7-5).

### 7-3. Gemini 가 자주 하는 실수 — 이런 결과가 나오면 다시 요청

| 증상 | 원인 | 이렇게 다시 요청 |
|------|------|------------------|
| 파이썬에서 `NameError: name 'z' is not defined` / `KeyError` | 타일 주소의 `{z}/{y}/{x}` 를 파이썬 **f-string** 안에 써서 파이썬이 변수로 해석 | "HTML 은 템플릿으로 따로 쓰고, 키 자리만 `replace` 로 치환해 줘" |
| 지도 자리가 **완전히 하얗거나 높이 0** | 지도 영역(`#map`)에 높이를 안 줌 | "지도 div 가 화면 높이를 다 채우게 CSS 를 고쳐 줘" |
| 지도 조각이 **흩어져** 보임 | Leaflet **CSS** 를 안 불러옴 | "leaflet.css 도 불러와 줘" |
| 회색 지도 + Network 에 타일 오류 | 주소 오류: `{x}/{y}` 순서 뒤바뀜, 위성에 `.png`, 레이어 이름 대소문자(`Base`, `Satellite`, `Hybrid`) | 타일 주소 형식을 다시 정확히 알려 주기 |
| 위성지도 위에 지명이 안 나옴 / 하이브리드만 보임 | Hybrid 는 **투명한 덧그림** — 위성 위에 겹쳐야 함 | "하이브리드는 Satellite 위에 Hybrid 를 겹친 레이어 그룹으로" |
| Google 지도·카카오맵·OpenStreetMap 이 나옴 | 브이월드를 안 씀 | "브이월드 WMTS 로" |

## 9. (심화) 지질도 겹쳐 보기 — 한국지질자원연구원 지질도 오버레이

브이월드 배경지도 위에 **한국지질자원연구원(KIGAM)의 지질도**를 반투명하게 겹쳐, 내가 찍은 지점이 어떤 지층·암석 위에 있는지
볼 수 있습니다. 지질도는 KIGAM **지오빅데이터 오픈플랫폼**의 OpenAPI(WMS)로 받아 옵니다.

> ⚠️ **수업 당일에 바로 하기는 어렵습니다.** 회원가입은 바로 되지만, OpenAPI 인증키는 **신청 후 승인**을 받아야 해서
> 당일에 나오지 않을 수 있습니다(브이월드 키는 신청 즉시 발급).
> → 해 보고 싶은 학생은 **수업 며칠 전에 미리 신청**하거나, **수업 뒤 과제**로 합니다.
> 본 실습(§1~§8)의 완성 기준에는 들어가지 않습니다.

### 9-1. KIGAM 인증키 신청 (미리)

1. https://data.kigam.re.kr (지오빅데이터 오픈플랫폼) → **회원가입** 후 로그인.
2. **OpenAPI 신청** 메뉴(마이페이지 쪽, 주소 `https://data.kigam.re.kr/my-openapi/request/`)에서 신청서를 냅니다.
   활용 목적은 예) `수업 실습 - 답사 지점 지도에 지질도 오버레이`. (신청서 항목·메뉴 이름은 바뀔 수 있습니다.)
3. **승인 대기** → 승인되면 OpenAPI 메뉴에서 인증키를 확인합니다. 승인 여부는 사이트에서 직접 확인하세요.
4. 사용 방법 안내: https://data.kigam.re.kr/guide/openapi ,
   레이어 목록: https://data.kigam.re.kr/map/openapimanual/openapiLayerList.html
5. 문의: 한국지질자원연구원 지질자원데이터연구실 (042-868-3111).

> 인증키는 브이월드 키와 마찬가지로 **비밀번호처럼** 다룹니다. Colab 🔑 보안 비밀에 `KIGAM_KEY` 로 넣으세요.

### 9-2. 알아 둘 것 — 지질도 WMS

| 항목 | 값 |
|------|-----|
| 주소 | `https://data.kigam.re.kr/openapi/wms` |
| 인증키 파라미터 | `key=발급받은키` |
| 주요 레이어 | `L_50K_Geology_Map` (1:5만 지질도), `L_250K_Geology_Map` (1:25만), `L_1M_Geology_Map` (1:100만) |
| 그 밖의 파라미터 | 표준 WMS — `service=WMS`, `request=GetMap`, `layers`, `srs`(1.3.0 은 `crs`), `bbox`, `width`, `height`, `format=image/png`, `transparent=true` |

- 브이월드 배경지도는 **타일(WMTS)**, 지질도는 **WMS**(요청한 범위를 그림 한 장으로 받아 옴)입니다.
  Leaflet 에서는 `L.tileLayer.wms(...)` 로 겹치면 됩니다.
- **지나치게 잦은 호출은 이용이 제한될 수 있다**고 안내돼 있습니다. 지도를 마구 확대·이동하며 시험하지 마세요.
- 1:5만 지질도는 **도폭(지도 한 장 단위)이 없는 지역**은 비어 보일 수 있습니다. 그럴 땐 1:25만으로 바꿔 보세요.

### 9-3. 프롬프트 예시

> 지금 지도 앱에 한국지질자원연구원 지질도를 겹쳐 보고 싶어. 기존 기능은 그대로 둬.
> 보안 비밀 KIGAM_KEY 를 읽어서 HTML 에 넣고, Leaflet 의 L.tileLayer.wms 로
> `https://data.kigam.re.kr/openapi/wms` 에 `key` 파라미터와 `layers=L_50K_Geology_Map`, `format=image/png`,
> `transparent=true` 로 요청해 줘. 투명도는 0.6 으로 하고, 지도 오른쪽 위 메뉴에서 1:5만 / 1:25만 지질도를 켜고 끌 수 있게 해 줘.
> KIGAM_KEY 가 비어 있으면 지질도 메뉴 없이 동작하게 해 줘.

더 해 볼 것:

> 지질도 투명도를 조절하는 슬라이더를 만들어 줘.

> 지점을 추가할 때 그 자리의 지질 정보를 같이 저장하고 싶어. (WMS `GetFeatureInfo` 요청 — 지원 여부는 직접 확인)

### 9-4. 안 될 때

| 증상 | 확인할 것 |
|------|-----------|
| 지질도 메뉴는 있는데 아무것도 안 겹쳐짐 | `F12` → Network 에서 `openapi/wms` 요청의 응답 확인. 키 오타·**승인 전 키**인지 |
| 응답이 `500` + "서비스에 일시적인 오류가 발생했습니다." 페이지 | 서버 고장처럼 보이지만 **키가 없거나 틀리거나 승인 전**일 때도 이렇게 나옵니다. 키부터 확인 |
| 응답이 `400 Bad Request` / `Request Blocked` | 키·파라미터 확인. 너무 잦은 요청이면 잠시 뒤 다시 |
| 특정 지역만 비어 있음 | 1:5만 도폭이 없는 지역 → 1:25만으로 |
| 배경지도가 안 보일 만큼 진함 | `opacity` 를 0.4~0.6 으로 |

> 참고 예시: `examples/vworld_map_sample.html` 의 `KIGAM_KEY` 부분 (키를 넣으면 지질도 메뉴가 생김).
> 이 문서의 KIGAM WMS 사용법은 공식 안내 페이지를 바탕으로 썼고, **실제 키로는 아직 시험하지 않았습니다.**
