# 강사용 수업 운영 안내 — Gemini 로 Conference Organizer(학회 시간표 앱) 만들기

## 수업 방식

- 학생은 **빈 Colab 노트북**에서 시작해, 옆 패널의 **Gemini 에게 프롬프트를 입력하며** 노트북을 구성한다.
- 결과물: 학회 시간표 웹앱 **Conference Organizer** — **HTML 파일 하나** (다운로드해서 PC 브라우저로 열어 사용).
- 강사는 처음에 **목표와 완성 기준**만 준다. 모범 답안 노트북은 **수업 마지막에 공개**해 비교하게 한다.
- 평가의 핵심은 코드 자체보다 **요구사항을 말로 정확히 전달하고, 결과를 검증하고, 고쳐 달라고 하는 과정**.
- 워크숍의 **두 번째 실습**이다. 첫 실습(브이월드 지도 앱, `docs/vworld_map_instructor_guide.md`)에서 Gemini 와 일하는 방식은 익혔다고 본다.
  **조건이 바뀌는 점을 꼭 짚을 것**: 지도 앱은 인터넷·CDN(Leaflet)을 썼지만, 이 앱은 **인터넷 없이** 열려야 하고 외부 라이브러리를 쓰지 않는다.
  학생들이 지도 앱 습관대로 CDN 을 넣거나 데이터를 `fetch` 로 따로 읽는 실수가 늘어날 수 있다.

| 학생에게 주는 것 | 시점 |
|------------------|------|
| `docs/conference_organizer_practice_guide.md` (완성 기준·프롬프트 예시·주의사항) | 수업 시작 |
| `conference.json` (드라이브 공유 또는 파일 배포) | 수업 시작 |
| 모범 답안 노트북 링크 + `docs/reference_notebook_guide.md` | 수업 마지막 |

> 프롬프트 예시(안내서 §4)를 주지 않고 더 열어 두고 싶으면 §1 완성 기준만 먼저 주고, 막히는 학생에게만 §4 를 보여 줘도 된다.

모범 답안 노트북: https://colab.research.google.com/github/jikhanjung/gsk2026-aiworkshop/blob/main/gsk2026_practice.ipynb

## 수업 전 점검

- [ ] **실습 PC·학생 계정에서 Gemini in Colab 이 켜지는지** 확인 — 학교 Workspace 계정은 관리자 설정으로 꺼져 있는 경우가 많다.
      안 되면 개인 Gmail 계정을 쓰게 공지. (나이·지역 제한도 있을 수 있음)
      **Gemini 패널은 새 노트북에서 닫혀 있는 것이 기본** — 화면 맨 아래 가운데의 파란 ✦ 버튼(**Toggle Gemini**)을
      눌러야 열린다. "Gemini 가 안 보여요" 질문의 대부분이 이것이므로 수업 시작 때 화면으로 보여 줄 것.
- [ ] **강사가 직접 한 번 전 과정을 Gemini 로 해 보기** — Gemini UI·기능은 자주 바뀐다. 안내서의 버튼 이름·위치가
      현재와 맞는지 확인하고 다르면 안내서를 고친다.
- [ ] 실습 PC 에서 **Chrome 다운로드 → 로컬 HTML 더블클릭 → 북마크 유지**가 되는지 (보안 정책으로 막히는 PC 있음).
- [ ] 데이터 배포 경로 테스트 (드라이브 공유 링크 권한: "링크가 있는 모든 사용자 – 뷰어").
- [ ] Gemini **사용량 한도**: 무료 계정은 한도에 걸릴 수 있다. 수업 시간이 길면 중간에 막히는 학생이 나올 수 있으니
      예비 계정 또는 짝 활동을 준비.
- [ ] Colab 의 **에이전트형 기능**(노트북 전체를 한 번에 생성하는 모드)을 허용할지 정해서 공지.
      허용하면 결과는 빨리 나오지만 단계별로 요구하고 검증하는 연습이 줄어든다.
- [ ] 데이터 재배포 금지 공지.

## 학생들이 막히는 지점과 개입 힌트

학생에게 답을 바로 주기보다 **어떤 프롬프트를 다시 써야 하는지** 묻는 방향으로.

| 증상 | 원인 | 힌트 |
|------|------|------|
| Colab 미리보기는 되는데 **다운로드한 파일은 빈 화면** | `fetch("conference.json")` — `file://` 에서 막힘 | "다운로드한 파일 하나만 있을 때 데이터는 어디서 오나요?" |
| 인터넷 끄면 깨짐 | CDN(Bootstrap 등) | 완성 기준 #2 다시 읽게 |
| Flask/Streamlit 코드 | 서버 앱으로 해석 | 단계 0 조건을 Gemini 에게 다시 말하게 |
| 파이썬 f-string `KeyError`/`SyntaxError` | JS 의 `{}` 와 충돌 | "HTML 을 템플릿으로 분리하고 치환" 방향 제시 |
| 기능 추가 후 예전 기능 사라짐 | 전체 재작성 | "기존 기능 유지" 명시 + 버전별 파일 저장 |
| 북마크가 안 남음 | 시크릿 창 / 다른 브라우저 / 미리보기와 혼동 | 어느 파일을 어떤 창에서 열었는지 확인 |
| 겹침 표시가 틀림 | `"9:00" < "10:00"` 문자열 비교, 날짜 무시 | 데이터의 시각 형식을 직접 확인하게 |
| 런타임 초기화로 파일 사라짐 | 장시간 유휴 | 데이터 재업로드 + "이전 셀 모두 실행" |
| 대화가 길어져 Gemini 가 엉뚱해짐 | 맥락 유실 | 새 대화 + 요구사항 요약 프롬프트 |

> 데이터는 시각이 모두 `HH:MM` 두 자리로 정규화돼 있어 문자열 비교도 우연히 맞는다.
> 겹침 계산을 토론 주제로 쓰려면 "다른 학회 데이터라면?" 질문을 던질 것.

## 평가 기준 (예시)

| 영역 | 비중 | 내용 |
|------|------|------|
| 완성 기준 충족 | 50% | 안내서 §1 의 9개 항목 (항목당 동일 배점). 강사가 제출 HTML 을 직접 열어 확인 |
| 과정 | 30% | 노트북에 남은 단계적 진행, 버전별 결과, 오류를 만났을 때 다시 요청한 흔적 |
| 회고 | 20% | 잘 먹힌 프롬프트, Gemini 가 틀린 순간과 대처, 모범 답안과 비교해 다른 점 |

채점 빠른 확인:
1. 제출 HTML 을 **빈 폴더에 혼자 두고**, **Wi-Fi 끈 상태**로 연다 → #1, #2.
2. 날짜·발표장 바꾸기, 저자 검색 → #3–#5.
3. 같은 시간대 다른 발표장 발표 2개 북마크 → 내 일정, 겹침 표시 → #6, #7, #9.
4. 탭 닫고 다시 열기 → #8. (채점 전에 다른 학생 파일의 북마크가 남아 있지 않게 Chrome 프로필을 분리하거나 북마크를 지운다 —
   Chrome 은 로컬 HTML 들이 저장 공간을 공유하므로, **같은 localStorage 키를 쓴 다른 학생 파일의 북마크가 보일 수 있다.**)

## 마무리: 모범 답안과 비교

모범 답안 노트북(`gsk2026_practice.ipynb`)은 같은 결과를 **단계별 템플릿**으로 만든다. 토론 질문:

- 데이터를 HTML 에 넣는 방법: 내 노트북은? (f-string / 치환 / fetch …) — 모범 답안은 `__DATA__` 자리 치환 + `</` 이스케이프.
- 화면 갱신: 버튼마다 따로 DOM 을 고치는가, **상태(state) 하나 + `render()`** 로 다시 그리는가.
- 북마크 저장 형식과 localStorage 키 이름. 다른 앱과 키가 겹치면?
- 시간 겹침 계산 방법. 시각이 `9:00` 처럼 한 자리면?
- Gemini 가 만든 코드 중 **이해하지 못한 채 넘어간 부분**은 무엇인가.
