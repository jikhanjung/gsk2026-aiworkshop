# 강사용 수업 운영 안내 — Gemini 로 브이월드 지도 앱 만들기

학생용 안내서: `docs/vworld_map_practice_guide.md`. **워크숍의 첫 번째 실습** — 빈 Colab 노트북에서 Gemini 에게 프롬프트로 요청하며
**HTML 파일 하나**짜리 지도 앱을 만든다. 두 번째 실습(Conference Organizer, `docs/conference_organizer_instructor_guide.md`)도 같은 방식이다.

첫 실습이므로 **Gemini 와 일하는 방법 자체**(조건 먼저 말하기, 작은 단계로 요청, 버전별 파일, 다운로드해서 확인,
콘솔 오류를 그대로 전달)를 여기서 충분히 연습시킨다. 화면 구성이 단순하고 다룰 데이터가 없어 이 연습에 집중하기 좋다.

이 실습에서 새로 배우는 것:
- **외부 API 인증키** 발급·관리 (브이월드 회원가입 → 인증키 → 서비스 URL)
- **비밀값을 코드에 적지 않기** — Colab 보안 비밀(Secrets, `google.colab.userdata`)
- **API 응답 확인** — 이미지가 와야 할 자리에 오류 XML 이 오는 경우
- 지도 라이브러리(Leaflet) + 타일 주소 규칙, 사용자 입력 저장(localStorage)·내보내기

| 학생에게 주는 것 | 시점 |
|------------------|------|
| 인증키 발급 안내(학생용 안내서 §2-1) + **서비스 URL 에 적을 값** | **수업 1주 전** (과제) |
| `docs/vworld_map_practice_guide.md` | 수업 시작 |
| 참고 샘플 `examples/vworld_map_sample.html` (선택) | 수업 마지막 |

## 수업 전 점검 — 꼭 직접 해 볼 것

### 1) 인증키와 "서비스 URL" — 가장 큰 불확실성

브이월드 인증키는 신청할 때 적은 **서비스 URL(도메인)** 과 실제 요청한 곳이 다르면 거절될 수 있다
(데이터 API 에서 `INCORRECT_KEY` 사례가 있음). 이 실습의 결과물은 **`file://` 로 여는 HTML** 이라 도메인이 없고,
Colab 미리보기는 Colab 쪽 주소에서 열린다. **배경지도 WMTS 가 도메인을 검사하는지는 직접 확인해야 한다.**
(2026-10-06 기준 확인된 것: 키 없는 요청에는 `등록되지 않은 인증키입니다.` XML 이 HTTP 200 으로 온다.)

강사 키로 세 곳에서 확인하고, **통과한 서비스 URL 값**을 학생에게 알려 준다.

| 확인 | 방법 | 결과 기록 |
|------|------|-----------|
| ① 파이썬 요청 | Colab 셀에서 `requests.get("https://api.vworld.kr/req/wmts/1.0.0/{키}/Base/7/49/109.png")` → `Content-Type` 이 `image/png` 인지 | |
| ② Colab 미리보기 | 지도 HTML 을 Colab 안에서 띄워 타일이 나오는지 | |
| ③ 다운로드한 파일 | `file://` 로 열어 타일이 나오는지 (F12 → Network 에서 타일 응답 확인) | |

- 서비스 URL 후보: 학교·개인 홈페이지 주소, `http://localhost`, `https://colab.research.google.com` 등.
  하나의 키에 여러 URL 을 등록할 수 있는지, 나중에 바꿀 수 있는지도 확인.
- **③이 안 되면** (file:// 차단):
  - (가) 결과물을 `python -m http.server` 로 띄워 `http://localhost:8000/…` 로 열게 하고, 서비스 URL 은 `http://localhost:8000` —
    "더블클릭으로 연다"는 조건만 완화한다.
  - (나) 키 없이 동작하는 옛 주소 `https://xdworld.vworld.kr/2d/Base/service/{z}/{x}/{y}.png` (샘플이 쓰는 방식,
    2026-10-06 기준 동작) — **비공식**이라 언제 막힐지 모름. 인증키 단계는 ①(파이썬 확인)까지만 실습하고 지도는 옛 주소로.
  - 어느 쪽이든 학생 안내서 완성 기준 #2 를 그에 맞게 고쳐서 배포.
- **유효기간·사용량**: 발급 화면에서 키 종류(개발/운영)와 유효기간, 일일 사용량 한도를 확인해 안내.
  30명이 동시에 확대·이동하면 타일 요청이 많다 — 개인 키를 각자 쓰게 하는 이유이기도 하다.

### 1-1) (심화) KIGAM 지질도 WMS — 학생 안내서 §9

학생 안내서 §9 의 지질도 오버레이는 **본 실습 완성 기준 밖**(심화·과제)이다. 그래도 학생에게 권하려면 강사가 먼저:

- [ ] **강사가 KIGAM OpenAPI 키를 미리 신청·승인받기** (https://data.kigam.re.kr → OpenAPI 신청). 승인까지 시간이 걸리므로
      수업 2주 전쯤. 승인 소요 기간을 기록해 학생에게 "언제까지 신청" 을 안내.
- [ ] 강사 키로 브이월드와 같은 세 곳에서 시험: ① 파이썬 `GetMap` 요청 ② Colab 미리보기 ③ **다운로드한 파일(`file://`)**.
      신청서에 도메인/서비스 URL 을 적게 되어 있는지, **도메인 제한이 있는지** 확인 — 있으면 `file://` 에서 안 될 수 있다.
- [ ] 레이어 이름(`L_50K_Geology_Map`, `L_250K_Geology_Map`, `L_1M_Geology_Map`), 좌표계(`EPSG:3857` 로 요청해도 되는지),
      `transparent=true` 가 실제로 투명 PNG 로 오는지 확인. 1:5만은 도폭이 없는 곳이 비어 보이므로 데모는 1:25만이 무난.
- [ ] 샘플 `examples/vworld_map_sample.html` 의 `KIGAM_KEY` 에 강사 키를 넣어 데모 → **데모 후 키를 지운 파일로 배포**.
- **주의 — 오류가 "서버 고장"처럼 보인다** (2026-10-06 확인): 키 없이 또는 잘못된 키로 `GetMap` 을 요청하면
  **HTTP 500 + HTML 페이지 "서비스에 일시적인 오류가 발생했습니다."** 가 온다 (오류 XML/빈 이미지가 아님).
  학생이 "KIGAM 서버가 죽었다" 고 하면 먼저 키(승인 여부·오타)를 의심할 것. Leaflet 에선 타일 오류로만 보인다.
  (`GetCapabilities` 는 같은 주소에서 404 XML — 문서화된 요청이 아닐 수 있음.)
- 지나치게 잦은 호출은 이용 제한될 수 있다고 안내돼 있음 → 30명이 동시에 시험하는 수업 시간엔 하지 않는 편이 안전.

### 2) 학생 사전 과제

- [ ] **회원가입 + 인증키 발급을 수업 전에** — 가입·이메일 인증에 시간이 걸리고, 수업 중 30명이 동시에 하면 막히는 학생이 꼭 나온다.
      "인증키 관리에서 상태 **승인** 화면을 캡처해 오기" 를 과제로.
- [ ] 키를 못 받아 온 학생 대비: 짝과 함께 하거나(키 공유는 짝 안에서만), 위 (나) 방식으로 진행.

### 3) Colab·Gemini

- [ ] **Gemini 패널은 새 노트북에서 닫혀 있다** — 화면 맨 아래 가운데 파란 ✦ 버튼(**Toggle Gemini**). 수업 시작 때 보여 줄 것.
- [ ] **보안 비밀(Secrets)**: 왼쪽 세로 아이콘 줄의 열쇠 아이콘. 처음 읽을 때 "노트북 액세스 허용" 창이 뜨는지 확인.
- [ ] 강사가 한 번 전 과정을 Gemini 로 해 보기 — Gemini 가 브이월드 타일 주소를 어떻게 쓰는지(틀리는지) 미리 보기.
- [ ] 실습 PC 에서 `unpkg.com`(Leaflet CDN)과 `api.vworld.kr` 이 막혀 있지 않은지 (학교 방화벽).

## 학생들이 막히는 지점과 개입 힌트

| 증상 | 원인 | 힌트 |
|------|------|------|
| Gemini 가 안 보임 | 패널이 닫혀 있음 | 맨 아래 가운데 ✦ (Toggle Gemini) |
| `등록되지 않은 인증키입니다` | 메일 인증 안 함, 키 복사 오류(공백), 승인 전 | 인증키 관리 화면 확인 |
| 도메인/URL 불일치 오류 | 서비스 URL 이 사전 점검 값과 다름 | 인증키 관리에서 서비스 URL 수정 |
| `NameError: z` / `KeyError` | 타일 주소 `{z}/{y}/{x}` 를 f-string 안에 넣음 | "파이썬이 중괄호를 어떻게 읽을까?" — 템플릿 + `replace` |
| 하얀 화면 | `#map` 높이 0 | 개발자 도구에서 지도 div 크기 보기 |
| 타일 조각이 흩어짐 | leaflet.css 누락 | |
| 회색 지도 | `{x}/{y}` 순서, `.png`/`.jpeg`, 레이어 대소문자 | Network 탭에서 타일 응답(이미지? XML?) 열어 보기 |
| Colab 미리보기만 안 됨 | 미리보기 주소가 서비스 URL 검사에 걸림 | 다운로드 파일 기준으로 판단 |
| 키가 셀에 그대로 | 편의 | "이 노트북을 제출하면 누가 키를 보나요?" |
| 키가 셀 출력에 찍힘 | `print(key)` | 출력 지우기(편집 → 모든 출력 지우기) |
| folium 사용 | 파이썬 지도 도구로 해석 | 클릭 추가·저장은 결국 JS — Leaflet 템플릿으로 |
| 다른 지점이 지워짐 | 좌표로 구분 | 고유 id |
| `<b>` 입력이 굵게 보임 | 이스케이프 누락 | XSS 이야기로 연결: "남이 준 JSON 을 불러오면?" |
| (심화) 지질도가 안 겹쳐짐, Network 에 `openapi/wms` 500 | KIGAM 키 미승인·오타 (오류 문구가 "일시적인 오류") | 키 승인 상태부터 확인 |

## 참고 샘플 `examples/vworld_map_sample.html`

Gemini + Colab 으로 만든 지도 앱 예시. 기능: 브이월드 기본지도, 클릭해 지점 추가, **입력 필드 직접 설정(스키마 관리)**,
localStorage 저장, JSON 내보내기/가져오기(덮어쓰기·병합 선택). 수업 마지막 비교·토론용으로 쓰기 좋은 지점:

- **인증키 없이 옛 주소**(`xdworld.vworld.kr/2d/Base/service/{z}/{x}/{y}.png`)를 쓴다 → 공식 WMTS(`api.vworld.kr/req/wmts/1.0.0/{키}/…/{z}/{y}/{x}`)와
  비교: 주소 형식(x·y 순서), 키, 언제 막힐지 모른다는 점.
- 팝업에 입력값·필드 이름을 **이스케이프 없이** `innerHTML` 로 넣는다 → 다른 사람의 JSON 을 불러오면 스크립트가 실행될 수 있음.
- 지점을 **좌표(소수 6자리)로 구분**해 삭제 버튼 id 를 만든다 → 같은 좌표 중복 시 문제, 고유 id 가 나은 이유.
- 잘한 점: localStorage 를 try/catch 로 감쌈, 가져오기에서 덮어쓰기/병합 선택, 스키마 중복 제거.
- 토론 질문: 내 결과물은 키를 어떻게 넣었나? HTML 을 친구에게 주면 키는? 키를 파일에 넣지 않으려면?
  (예: 앱 첫 실행 때 키를 입력받아 그 브라우저의 localStorage 에만 저장)
