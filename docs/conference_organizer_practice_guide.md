# Gemini 와 함께 Conference Organizer(학회 시간표 앱) 만들기 — 학생용 실습 안내서

**한국어** | [English](conference_organizer_practice_guide.en.md)

Google Colab 옆의 **Gemini** 에게 말로 부탁하면서, 학회 발표 데이터(JSON)로
**내 PC 브라우저에서 쓰는 학회 시간표 앱 Conference Organizer(HTML 파일 하나)** 를 만드는 실습입니다.
코드를 직접 다 짜는 것이 아니라, **원하는 것을 정확히 설명하고, 결과를 확인하고, 고쳐 달라고 하는 과정**을 연습합니다.

---

## 1. 무엇을 만드나 — 완성 기준

아래를 모두 만족하면 성공입니다. 실습 내내 이 표를 옆에 두고 확인하세요.

**꼭 되어야 하는 것**

| # | 기준 | 확인 방법 |
|---|------|-----------|
| 1 | **HTML 파일 하나**로 동작한다 (다른 파일·서버 필요 없음) | 다운로드 폴더의 그 파일 하나만 다른 폴더로 옮겨 열어도 동작 |
| 2 | **인터넷 없이** 열린다 | Wi-Fi 를 끄고 열어 봐도 화면이 정상 |
| 3 | 날짜별로 발표를 볼 수 있다 | 날짜를 바꾸면 목록이 바뀜 |
| 4 | 발표장(룸)별로 볼 수 있다 | 동시에 열리는 발표장을 골라 볼 수 있음 |
| 5 | 제목·저자로 **검색**된다 | 아는 저자 이름을 넣어 보기 |
| 6 | 발표를 **북마크(☆)** 할 수 있다 | |
| 7 | 북마크한 발표가 **내 일정**에 시간순으로 모인다 | 날짜별·시간순인지 |
| 8 | 브라우저를 **닫았다 다시 열어도 북마크가 남아 있다** | 탭을 닫고 파일을 다시 열기 |
| 9 | **시간이 겹치는 북마크**를 알려 준다 | 같은 시간 다른 발표장 발표 두 개를 북마크 |

**더 하면 좋은 것** — 발표를 누르면 상세 정보, 세션별 보기, 휴대폰 화면에 맞는 디자인,
북마크 내보내기/불러오기, 오늘 날짜 자동 선택, 인쇄용 내 일정 …

> **실습 1(브이월드 지도 앱)과 다른 점**: 지도 앱은 지도 그림을 인터넷에서 받아 와서 Leaflet 같은 외부 라이브러리(CDN)를 써도 됐습니다.
> 이번 앱은 **인터넷 없이** 열려야 하므로 외부 라이브러리를 쓰지 않고, 데이터도 HTML 안에 넣습니다(기준 #1, #2).
> 단계 0 에서 Gemini 에게 이 조건을 분명히 알려 주세요.

## 2. 준비

| 준비물 | 비고 |
|--------|------|
| **개인 Google 계정** | 학교·회사 계정은 Gemini 가 꺼져 있을 수 있습니다 (§7-1) |
| PC + **Chrome** | 휴대폰·태블릿은 비권장 |
| 데이터 파일 `conference.json` | 강사가 공유한 [구글 드라이브 링크](https://drive.google.com/file/d/1RIQlIQLFfPRQNLve4ZU9KyTKr1TMBvy4/view?usp=sharing) |

1. https://colab.research.google.com → **새 노트북**.
2. 노트북 이름을 바꿉니다 (예: `학회앱_홍길동.ipynb`). 노트북은 내 드라이브의 `Colab Notebooks` 폴더에 저장됩니다.
3. 화면 **맨 아래 가운데의 파란 동그라미 ✦ 버튼**(마우스를 올리면 **Toggle Gemini**)을 눌러 Gemini 패널을 엽니다.
   새 노트북을 열면 Gemini 패널이 **닫혀 있는 것이 기본**이라 처음엔 안 보입니다. 다시 누르면 닫힙니다.
   버튼이 아예 없으면 §7-1.
4. 데이터 파일을 런타임에 가져옵니다. 셋 중 하나:
   - **링크로 받기 (권장)**: 새 코드 셀에 아래 두 줄을 붙여 넣고 실행 → 왼쪽 📁 파일 패널에 `conference.json` 이 보이면 성공.
     ```
     !wget -q -O conference.json "https://drive.google.com/uc?export=download&id=1RIQlIQLFfPRQNLve4ZU9KyTKr1TMBvy4"
     !ls -l conference.json
     ```
   - **업로드**: [링크](https://drive.google.com/file/d/1RIQlIQLFfPRQNLve4ZU9KyTKr1TMBvy4/view?usp=sharing)에서 PC 로 내려받은 뒤 → 왼쪽 📁 파일 패널 → 업로드 버튼 → `conference.json`
     (또는 Gemini 에게 "파일 업로드하는 셀 만들어 줘")
   - **드라이브**: 드라이브에 `conference.json` 을 넣어 두고 Gemini 에게 "드라이브 연결해서 이 파일 읽는 코드 만들어 줘"
     (권한 창에서 허용)

> ⚠️ 런타임에 가져온 파일은 **런타임이 끊기면 사라집니다.** 오래 쉬었다 오면 다시 받아야 합니다(§7-2). 위의 `!wget` 셀을 다시 실행하면 됩니다.

## 3. 작업하는 방법 — 한 바퀴 돌리기

```
① 원하는 것을 Gemini 에게 말한다
② Gemini 가 준 코드를 읽어 보고 셀에 넣어 실행한다
③ 결과 HTML 을 미리보기 / 다운로드해서 브라우저로 열어 본다
④ 완성 기준(§1)과 비교 → 안 되는 점을 구체적으로 다시 말한다
```

이 바퀴를 여러 번 돕니다. **한 번에 다 만들어 달라고 하지 마세요.** 작은 단계로 나눌수록 잘 됩니다.

## 4. 단계별 진행 — 프롬프트 예시

아래 프롬프트는 **예시**입니다. 그대로 복사하기보다 자기 말로 바꿔 쓰고, 결과를 보며 덧붙이세요.

> **프로그래밍 용어를 몰라도 됩니다.** Gemini 에게는 ① **무엇을 하고 싶은지** ② **화면이 어떻게 보이면 좋겠는지**
> ③ **어떻게 확인할 건지**를 평소 말로 설명하세요. 어떤 기술을 쓸지는 Gemini 가 고릅니다.
> 다만 **지켜야 할 조건**(파일 하나, 더블클릭으로 열기, 인터넷 없이)은 처음에 꼭 말해 두세요. 이 조건이 가장 중요합니다.

### 단계 0. 하고 싶은 것과 조건 알려 주기

> 학회 발표 일정이 담긴 파일(`conference.json`)이 있어. 이걸로 학회 기간에 **내가 들을 발표를 고르고 일정을 짜는 프로그램**을 만들고 싶어.
> 조건은 이래:
> - 결과는 **파일 하나**였으면 좋겠어. 내려받아서 **더블클릭하면 바로** 열리게. 다른 프로그램을 설치하거나 켜 둘 필요 없이.
> - 학회장에서는 와이파이가 안 될 수도 있으니까 **인터넷이 없어도** 똑같이 열리고 동작해야 해.
>   그러니까 발표 정보도 전부 그 파일 하나 안에 들어 있어야 해.
>
> 나는 프로그래밍을 잘 몰라. 한 번에 다 만들지 말고 단계별로 같이 하자.
> 단계마다 내가 뭘 하면 되는지(어떤 셀을 실행하고, 무엇을 확인하는지)도 알려 줘. 먼저 이 파일에 뭐가 들어 있는지부터 보자.

- Gemini 가 쓰는 말 중 모르는 게 있으면 바로 물어보세요: "○○가 뭐야? 쉽게 설명해 줘."

### 단계 1. 데이터에 뭐가 들어 있는지 보기

> 업로드한 `conference.json` 안에 어떤 내용이 들어 있는지 **쉽게** 보여 줘.
> 어떤 묶음들이 있고 각각 몇 개인지, 발표 하나에는 어떤 정보가 들어 있는지 예시로 하나 보여 줘.

- 실행 결과를 **직접 보세요.** 발표 목록, 날짜, 시작·끝 시각, 발표장, 제목, 저자 … 가 어떤 **영어 이름**으로 들어 있는지 확인합니다.
- Gemini 가 이 이름을 **지어내는** 일이 많습니다. 화면에 나온 이름(예: `talks`, `room`)을 다음 요청에 **그대로 따라 쓰면** 정확해집니다.
  뜻을 몰라도 됩니다 — 보이는 대로 옮겨 적으면 됩니다.

> 날짜별, 발표장별로 발표가 몇 개씩 있는지 표로 보여 줘.

### 단계 2. 첫 화면 — 발표 목록

> 이제 발표 목록을 보여 주는 화면을 만들어 줘. 우선 **첫날 발표만**.
> 발표마다 카드처럼 **시간, 발표장, 제목, 첫 번째 저자**가 보이게 해 줘.
> 결과는 내 PC 로 내려받을 수 있는 파일 `app_v1.html` 로 만들고, Colab 안에서도 미리 볼 수 있게 해 줘.

- 내려받은 파일을 **더블클릭해서 브라우저로** 열어 보세요. Colab 미리보기만으로 끝내지 마세요.
- 미리보기에서는 되는데 내려받은 파일이 비어 있으면 §7-3 표 첫 줄.

### 단계 3. 날짜·발표장 고르기, 검색

> 지금 되는 건 그대로 두고, 화면 위쪽에 **날짜 버튼**과 **발표장 버튼**을 넣어 줘.
> 누르면 그 날짜, 그 발표장의 발표만 보이게. 그리고 **제목이나 저자 이름으로 찾는 검색창**도 넣어 줘.
> 파일은 `app_v2.html`.

- 확인: 아는 저자 이름으로 검색해 보기, 날짜를 바꿔 보기.

### 단계 4. 관심 발표 표시와 내 일정

> 이제 내 일정을 짜고 싶어. 지금 되는 건 그대로 두고:
> - 발표마다 **별(☆) 버튼**을 달아서, 누르면 관심 발표로 표시되게 해 줘.
> - 프로그램을 **껐다 켜도** 표시한 게 남아 있어야 해.
> - **"내 일정"** 화면을 따로 만들어서, 표시한 발표를 날짜별로 **시간 순서대로** 모아 보여 줘.
> - 시간이 **겹쳐서 둘 다 들을 수 없는** 발표는 빨갛게 표시해서 알려 줘.
>
> 파일은 `app_v3.html`.

- 겹침 확인: 같은 시간대 서로 다른 발표장의 발표 두 개를 표시해 보세요.
- 껐다 켜기 확인: 탭을 닫고 파일을 다시 열기.

### 단계 5. 다듬기 (자유)

자기 앱을 써 보면서 불편한 점을 고쳐 달라고 하세요. 예:

> 발표를 누르면 자세한 정보(저자 전체 등)가 나오게 해 줘. 같은 세션의 다른 발표 목록도 보여 줘.

> 휴대폰 화면에서도 보기 좋게 바꿔 줘. 아래쪽에 메뉴 버튼들이 있으면 좋겠어.

> 내 일정을 **파일로 저장**했다가, 다른 컴퓨터에서 **불러올** 수 있게 해 줘.

## 5. 프롬프트 잘 쓰는 법

**기술 용어 대신, 원하는 것과 본 것을 구체적으로.**

| 이렇게 | 대신 이렇게 하지 말기 |
|--------|----------------------|
| "날짜 버튼을 누르면 **그 날짜 발표만** 보이게 해 줘" | "필터 기능 넣어 줘" |
| "**지금 되는 건 그대로 두고** 검색창만 추가해 줘" | "검색 기능 추가해 줘" (다른 기능이 사라지기도 함) |
| **본 그대로** 말하기: "별을 눌렀는데 내 일정에 안 나와" + 빨간 오류 문구 복사 | "안 돼" |
| 단계 1 화면에 나온 **이름을 그대로** 따라 쓰기 (`talks`, `room` …) | "시간", "장소" 같은 말만 쓰기 (Gemini 가 이름을 지어냄) |
| 결과 파일을 **버전별 이름**으로 (`app_v1`, `app_v2` …) | 같은 이름에 계속 덮어쓰기 |
| 모르는 말이 나오면 "○○가 뭐야? 쉽게 설명해 줘" | 모르는 채로 넘어가기 |

- 대화가 길어지면 Gemini 가 앞의 조건을 잊습니다. 이상해지면 **새 대화**를 열고 단계 0 의 조건과
  지금까지 만든 기능을 요약해서 다시 알려 주세요. ("지금까지 이런 기능을 만들었어: … 이어서 ○○를 하고 싶어")
- Gemini 가 준 코드를 다 이해하지 않아도 됩니다. 다만 **실행 전에** "이 코드가 하는 일을 한두 줄로 설명해 줘" 라고 물어보는 습관을 들이세요.
- 학생마다 결과가 다른 것이 정상입니다. 완성 기준(§1)을 만족하면 됩니다.

## 6. 결과 확인하기

1. 다운로드 폴더의 HTML 파일을 **더블클릭** → Chrome 에서 열림. 주소창이 `file:///…` 로 시작하면 정상.
2. §1 완성 기준을 하나씩 확인.
3. 화면이 하얗거나 버튼이 반응하지 않으면 **`F12` → Console** 탭의 빨간 오류를 확인하고,
   **그 오류 문구를 그대로 복사해** Gemini 에게 알려 주세요.
   (Gemini 는 내 브라우저 화면을 볼 수 없습니다. Colab 셀 오류와 달리 브라우저 오류는 직접 전달해야 합니다.)

## 7. ⚠️ 주의할 점

### 7-1. Gemini 사용

**Gemini 패널이 안 보이면**

- **먼저 화면 맨 아래 가운데의 파란 ✦ 버튼(Toggle Gemini)을 누르세요.** 패널은 처음에 닫혀 있습니다.
  셀 안의 "generate with AI" 링크로도 열 수 있습니다.
- 그 버튼 자체가 없으면:
  - **계정 나이 18세 이상**, **지원 지역**이어야 Colab 의 AI 기능이 나옵니다.
  - **학교·회사(Workspace) 계정**은 관리자가 꺼 두었을 수 있습니다 → **개인 Gmail** 로 로그인한 창에서 다시 열기.
    (오른쪽 위 프로필 사진이 어느 계정인지 확인. 여러 계정이 로그인돼 있으면 다른 계정으로 열려 있기 쉽습니다.)
  - 새로고침(`F5`), 시크릿 창에서 개인 계정으로 열기, 광고 차단 확장 프로그램 끄기.
  - 그래도 안 되면 강사에게 알리고 짝과 함께 진행합니다. (Colab 쪽 일시적 오류일 수도 있습니다.)

**그 밖에**

- **사용량 제한**: 무료 계정은 일정 시간 동안 쓸 수 있는 횟수에 한도가 있습니다. 짧은 질문을 자주 보내기보다
  요구사항을 모아 한 번에 정확히 보내세요.
- **데이터를 채팅창에 붙여 넣지 마세요.** 파일이 커서 잘리고, Gemini 가 일부만 보고 판단합니다.
  파일은 런타임에 올리고, "코드로 읽어서 확인해 줘" 라고 하세요.
- Gemini 는 그럴듯한 **틀린 답**을 자신 있게 줄 수 있습니다. 항상 실행 결과로 확인하세요.

### 7-2. Colab 런타임

- **런타임이 끊기면 업로드 파일과 만든 HTML 이 사라집니다** (노트북 셀은 남음).
  → 메뉴 **런타임 → 이전 셀 모두 실행** 으로 복구 (`!wget` 셀이 위에 있으면 데이터도 다시 받아짐).
  → 잘 된 버전은 바로 다운로드하거나 드라이브에 저장.
- 셀은 **위에서부터 순서대로** 실행되어야 합니다. 중간 셀만 실행하면 `… is not defined` 오류가 납니다.

### 7-3. Gemini 가 자주 하는 실수 — 이런 결과가 나오면 다시 요청

"이렇게 말하기" 의 핵심은 **본 것을 그대로 설명하고, 오류 문구가 있으면 붙여 넣는 것**입니다. "왜 그런가" 칸은 몰라도 됩니다.

| 이런 일이 생기면 | 이렇게 말하기 | 왜 그런가 (몰라도 됨) |
|------------------|---------------|------------------------|
| Colab 미리보기에서는 되는데, **내려받은 파일을 열면 목록이 비어 있음** | "미리보기에서는 발표가 보이는데, 내려받은 파일을 열면 비어 있어. 파일 하나만으로 보여야 해" | 발표 데이터를 파일 밖에서 따로 읽어 옴 (`fetch`) — 내 PC 에선 막힘 |
| **인터넷을 끄면** 모양이 깨짐 | "인터넷을 끄고 열었더니 모양이 깨져. 인터넷 없이도 똑같이 보여야 해" | 디자인 도구를 인터넷(CDN)에서 불러옴 |
| "서버를 실행하세요", Flask, Streamlit, `localhost` 같은 말이 나옴 | "따로 뭘 켜 두지 않고, 파일을 더블클릭하는 것만으로 열리게 해 줘" | 웹 서버 프로그램으로 만듦 |
| 셀을 실행했더니 빨간 오류 (`KeyError`, `SyntaxError` 등) | "셀을 실행했더니 이런 오류가 나와: (오류 붙여 넣기)". 같은 오류가 반복되면 "화면 내용(HTML)은 파이썬 코드와 따로 두고, 데이터 넣을 자리만 바꿔 넣는 식으로 해 줘" | 화면 코드의 `{ }` 를 파이썬이 자기 것으로 착각 (f-string) |
| 화면이 **갑자기 하얗게** 됨 | "화면이 하얗게 나와. F12 콘솔에 이런 빨간 글씨가 있어: (붙여 넣기)" | 데이터 속 특정 글자(`</script>`)가 화면 코드를 끊음 등 |
| 새 기능을 넣었더니 **예전 기능이 사라짐** | "날짜 버튼이 없어졌어. 전에 되던 기능은 모두 그대로 두고 고쳐 줘" | 코드를 처음부터 다시 쓰면서 빠뜨림 |
| 제목에 `<` 같은 기호가 있는 발표에서 **화면이 깨짐** | "이 발표에서 화면이 깨져: (제목). 어떤 글자가 들어 있어도 그대로 보이게 해 줘" | 글자를 화면 코드로 해석 (이스케이프 누락) |
| **시간 순서가 이상함** (9시 발표가 10시 뒤에) | "9시 발표가 10시 발표보다 뒤에 나와. 시간 순서대로 보여 줘" | 시각을 글자로 비교 |
| 화면에 `undefined` 가 보이거나 정보가 빈칸 | "○○ 자리에 undefined 라고 나와. 단계 1 에서 본 이름은 `…` 이야" | Gemini 가 데이터 이름을 지어냄 |

### 7-4. 다운로드와 북마크

- **Chrome 권장.** 처음 다운로드할 때 "여러 파일 다운로드 허용" 이 뜨면 허용.
  다운로드가 안 되면 왼쪽 📁 파일 패널에서 파일 오른쪽 클릭(⋮) → 다운로드.
- 같은 이름으로 여러 번 받으면 `app (1).html` 처럼 쌓입니다. **최신 파일을 열고 있는지** 확인.
- 북마크는 **그 PC 의 그 브라우저**에만 저장됩니다. 시크릿 창은 닫으면 사라집니다.
- Chrome 에서는 내 PC 의 HTML 파일들이 저장 공간을 함께 쓰므로, v2 에서 한 북마크가 v3 에서 보일 수 있습니다(정상).
- Colab 미리보기의 북마크와 다운로드한 파일의 북마크는 **별개**입니다.

### 7-5. 데이터·결과물

- 만든 HTML 에는 **데이터 전체가 들어 있습니다.** 파일 공유 = 데이터 공유입니다.
- 실습 데이터는 **수업용**입니다. 웹사이트·GitHub·SNS 등 공개된 곳에 올리지 마세요.
